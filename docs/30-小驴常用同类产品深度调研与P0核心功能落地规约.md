# 小驴常用 · 同类产品深度调研与 P0 核心功能落地技术规约

> **适用仓库**：`小驴常用/` (`xiaolv-common`)  
> **对标产品**：Raycast Snippets、Alfred Text Expander、Paste、Maccy、Drafts  
> **核心哲学**：将碎片效率工具打造成“零延迟、高安全、可编程”的思源输入加速器。

---

## 一、 同类标杆比对与核心痛点穿透

| 标杆产品 | 最具杀伤力的机制 | 解决的传统痛点 | 小驴常用吸收与创新结合点 |
| :--- | :--- | :--- | :--- |
| **Raycast** | **动态表单变量片段 (Form Inputs)** | 静态代码片段死板，每次粘贴后还要手动去修改名字、项目名、日期 | **交互式动态表单片段**：支持 `{name}`、`{date:YYYY-MM-DD}`、`{clipboard}` 弹窗快速填表合成 |
| **Paste / Maccy** | **隐私排除与敏感信息脱敏** | 密码、银行卡、Token 复制后全留存在剪贴板历史中，导致严重安全隐患 | **剪贴板隐私护盾**：正则自动识别并脱敏敏感串，支持密码管理器进程自动排除 |
| **Drafts** | **极速沙盒与一键分发动作 (Actions)** | 随手记下的临时文字堆在沙盒里，无法快速沉淀到笔记各处 | **瞬时记事智能路由中枢**：记完一键“追加今日日记/存为新文档/转入闪卡收件箱” |

## 二、 P0 级别建议加入的核心功能技术方案

### 功能 1：Raycast 级交互式动态表单变量代码片段（Dynamic Snippets）
- **功能逻辑**：
  - 在代码片段中使用变量宏语法：
    ```markdown
    你好 {{name}}，关于 {{project}} 的进度报告已整理完毕。
    会议时间：{{date:YYYY-MM-DD HH:mm}}
    参考资料：{{clipboard}}
    ```
  - 触发插入该片段时，系统自动弹出一个轻量紧凑的表单浮窗（聚焦第一个输入框，支持 `Tab` 切下一个，`Enter` 确认）；
  - 填完后自动合成最终文本并贴入思源光标处，效率提升 10 倍！

### 功能 2：剪贴板隐私护盾与敏感脱敏（Clipboard Privacy Shield）
- **功能逻辑**：
  - **敏感内容正则过滤**：自动识别常见的身份证号（18位）、中国大陆手机号（11位）、16-19位银行卡号、JWT Token 或 API Key（`sk-...`）；
  - 在剪贴板历史列表中自动展示为 `138****1234` 或 `sk-***[已脱敏]`；
  - **白名单保护模式**：支持一键开启“纯隐私模式”，历史记录仅保留在内存，思源重启即焚。

### 功能 3：瞬时记事沙盒一键智能路由中枢（Scratchpad Dispatch Router）
- **功能逻辑**：
  - 全局快捷键呼出极简随手记沙盒（Scratchpad）；
  - 记录完毕后，底部常驻 3 个一键路由动作：
    1. **`[📝 追加至今日日记]`**：自动附加到 Daily Note 末尾；
    2. **`[📄 存为新文档]`**：按当前首行作为标题在收件箱笔记本新建独立文档；
    3. **`[💡 投递至小驴闪卡]`**：直接作为待加工摘录进入闪卡收件箱。

## 三、 双端 UI 与全生态质量红线
1. 桌面端快捷键流：表单变量弹窗支持全键盘流无鼠标操作（Tab/Enter/Esc）；
2. 零卡死红线：剪贴板监听严格限制历史单条上限（≤ 2MB），大文本/二进制文件自动降级拦截，杜绝主进程卡死。
