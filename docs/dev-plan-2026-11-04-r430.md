# 手机端完整开发与 Mobile Spec v1 落地账本（2026-11-04 · T-0827~T-0830 / R430）

## 一、 背景与实施目标

依据【小驴生态 · 手机端完整开发 · Mobile Spec v1】统一规范要求：
1. 标准库 `src/libs/lv-notice-kit.ts` 由快门同步至最新版，严禁改动该文件；
2. 手机端统一改挂 `lvLaunchpad.ensureMobileEntry()`，清理函数挂 `onunload`，`onunload` 严禁出现 `petal`；
3. 宿主形态 100vw/vh 确认 safe-area-inset 四向适配；
4. 页面骨架（顶部搜索框 → 结果列表 → 底部操作条），触控目标 ≥52px，`touch-action: manipulation`；
5. 手机核心场景是"搜片段 → 点一下 → 已复制 → 切微信粘贴"，点击复制强化 `lvLaunchpad.haptic(12)` + inline 打勾，坚决不弹窗；插入目标场景在手机端维持现有降级提示，文案改为"已复制，去目标应用粘贴"；
6. 性能纪律：结果列表分页首屏 ≤50 条；深浅色全走 `--b3-theme-*` 变量；
7. 功能取舍：前显 = 片段搜索、高频片段直达行（frecency 前 5 个置顶 chips）；后收 = 片段编辑、宏配置、包管理、导入导出（全部仅桌面，移动端隐藏）；
8. `lvLaunchpad.register` 的 actions 重写为 4 个手机直办动作；`lvOmnisearch` provider 覆盖手机高频实体。
