# 小驴常用 v0.10.15 发布说明

## 概述

小驴常用 `v0.10.15` 带来全角半角双向规范化引擎、UTF-8 Base64 与 URL 编解码实用宏及 Markdown 引用/围栏工具。
当前版本仅在本地仓库更新，全套 815/815 项单元测试全绿通过，遵照用户指令封禁期不推送远程 GitHub。

## 详细变更

1. **全角/半角智能规范化引擎 (`convertWidth`)**：
   - 支持全角数字（`０-９` -> `0-9`）、全角英文字母（`Ａ-Ｚ`、`ａ-ｚ` -> `A-Za-z`）、全角空格与标点符号智能转换；
   - 动作菜单接线「🔤 全角转半角并复制」；
   - 表单快捷格式栏新增「✦ 全角转半角」快捷工具，支持局部选区与全文转换。

2. **Base64 UTF-8 安全编解码引擎与动态宏**：
   - 彻底解决浏览器与 Node.js 下 CJK 中文字符编码抛出 `CharacterOutofRange` 异常的问题；
   - 扩充宏语法：`{{xlc:base64:encode|...}}` 与 `{{xlc:base64:decode|...}}`；
   - 动作菜单新增「🔒 Base64 编码并复制」与「🔓 Base64 解码并复制」；
   - 表单快捷变量栏新增 `{{xlc:base64:encode|Hello}}`，快捷格式栏新增「✦ Base64」。

3. **URL 组件编解码纯函数与动态宏**：
   - 扩充宏语法：`{{xlc:url:encode|...}}` 与 `{{xlc:url:decode|...}}`；
   - 动作菜单新增「🔗 URL 组件编码并复制」与「🔗 URL 解码并复制」；
   - 表单快捷变量栏新增 `{{xlc:url:encode|...}}`，快捷格式栏新增「✦ URL编码」。

4. **Markdown 引用语法切换与代码围栏包裹**：
   - 实现 `toggleMarkdownBlockquote` 纯函数，智能判定全文或选区是否已有 `> ` 引用语法并双向反转；
   - 动作菜单新增「> 切换 Markdown 引用 (>) 并复制」；
   - 表单快捷格式栏新增「✦ 引用包裹」。
