# 小驴常用 · 候选功能清单（用户决策结果记录）

> **规则说明**：
> 1. 存量优化期间禁止私自直接实现新功能；
> 2. 凡在审计与实测中发现可以做得更好、或体验能更完整的点，在此详尽记录；
> 3. 由用户审阅后决策：批准的转入待办池（`docs/todo-pool.md`），不做的标注原因后永久留存，避免反复讨论。

## 候选功能列表与决策记录（2026-11-01 决策）

### CAND-001：剪贴板搜索流支持多格式过滤器（纯文本 / 图片 / 富文本）
- **是什么**：在主搜索面板的「剪贴板」范围（`filter.scope.clipboard`）下，提供轻量格式切换胶囊（全部 · 纯文本 · 图片素材 · 代码片段）。
- **解决什么问题**：当用户在思源内外高频复制文本、网页代码和截图时，剪贴板历史混排在一起；想要快速提取刚刚截取的一张图片沉淀为常用素材时，需要在大量文本中翻找。
- **影响哪类用户**：图文混排创作者、设计师、经常收集图片与代码片段的技术用户。
- **预估成本**：低（约 0.5 人天，底层 `clipboard.ts` 已支持类型标记，仅需在 UI 增加筛选派发）。
- **与现有功能是否重叠**：否。现有 `filter.type` 是库内条目类型筛选，剪贴板流目前按单一时间轴平铺展示。
- **用户决策**：**【已批准】** → 转入待办池：`TODO-FEAT-001`

### CAND-002：动态变量填空卡片提供「最近输入值」极速点填胶囊
- **是什么**：在唤起动态变量表单（`VariableFormDialog`）时，在各变量输入框右侧或上方呈现一个微型气泡胶囊，展示该变量上一次使用的输入值，点击直接填入。
- **解决什么问题**：在连环处理售后、发票开具或邮件回复时，某些变量（如客户名称、项目编号、日期）在短时间内完全相同；虽然现有系统支持成套保存「预设方案」，但临时偶发复用单个字段仍需重复键盘键入。
- **影响哪类用户**：高频客服、售后沟通、商务发票与合规填单人员。
- **预估成本**：低（约 0.5 人天，`variable-memory.ts` 中已有持久化记忆机制，仅需在前端表单挂载推荐 Chip）。
- **与现有功能是否重叠**：否。与成套保存的「方案预设」互补，主打单字段秒级复用。
- **用户决策**：**【已批准】** → 转入待办池：`TODO-FEAT-002`

### CAND-003：搜索结果列表虚拟滚动触底反馈与区间指示
- **是什么**：当检索结果超过 50 条时，列表滚动到底部展示优雅的「✓ 已加载全部常用语」微型分割线，并在底栏实时显示 `[可视范围 / 总条数]`（如 `1-12 / 86`）。
- **解决什么问题**：在全域跨笔记本大范围检索时，用户在快速滚动列表中容易产生「后面是否还在异步加载」的心理不确定性，需要明确的触底闭环反馈。
- **影响哪类用户**：拥有 300+ 常用条目的大型资产库用户及全域重度检索用户。
- **预估成本**：极低（约 0.3 人天）。
- **与现有功能是否重叠**：否。现有底栏仅显示静态命中总数，缺乏动态滚动区间与触底确定性反馈。
- **用户决策**：**【已批准】** → 转入待办池：`TODO-FEAT-003`

- **与现有功能是否重叠**：否。现有 Dock 为单层分组。

### CAND-005：设置中心增加本地周期性自动安全快照备份
- **是什么**：在设置中心提供「本地定时快照备份」可选开关（如每 7 天自动将常用资产导出为带时间戳的本地 zip 归档存放在插件数据目录）。
- **解决什么问题**：当用户在思源中批量误删块、误清空文档或意外断电损坏块属性时，可一键从本地快照还原，避免重要常用话术彻底灭失。
- **影响哪类用户**：对核心常用资产数据安全敏感、且经常进行大规模编辑操作的用户。
- **预估成本**：中（约 0.8 人天，复用现有 `exportBundle` 导出链路与侧车持久化）。
- **与现有功能是否重叠**：否。现有仅支持用户手动在设置页点击导出。
- **用户决策**：**【不采纳（永久留存）】** —— 思源笔记本体已具备完善的本地文档历史与快照恢复机制，且插件数据真源为思源块，无需在插件层冗余进行本地周期性 ZIP 快照，避免增加不必要的磁盘 I/O。
