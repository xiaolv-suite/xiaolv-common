## [0.8.2] — 2026-10-27

行尾操作按钮场景化定制与剪贴板隐私清空：全域块与剪贴板行尾操作按钮专属定制 (一键收录/定位/存常用语)、一键清空剪贴板历史暂存、对外桥扩充剪贴板读取、735 项单测全绿。

### 新增与核心优化

- **列表行尾操作按钮精准分流**：
  - **剪贴板条目**：行尾展示 `✦ 沉淀为常用语 (Alt+S)` 快捷按钮，支持鼠标一键点选沉淀；
  - **全库思源块条目**：行尾展示 `✦ 一键收录 (Alt+S)`（已收录显示 `✓`）与 `↗ 在思源中定位源块` 双按钮；
  - **常用库条目**：精准保留 `★/☆ 收藏切换`，彻底消除全域块误收藏导致的侧车逻辑污染。
- **剪贴板视图一键清空暂存**：在剪贴板作用域下，统计提示条新增 `[清空暂存]` 快捷操作，一键清除所有会话剪贴板缓存，保障个人隐私安全。
- **对外桥扩充剪贴板流读取**：`XlcBridgeApi` 与 `protocolCommands` 暴露 `getClipboardHistory()`，供外部 Quicker 与桌面脚本无 UI 获取暂存流。
