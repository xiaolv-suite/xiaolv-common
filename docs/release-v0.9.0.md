### 新增与核心优化

- **复合高级搜索语法编译器**：在全域块检索与常用库检索中全面支持 `type:code`、`tag:标签`、`#标签`、`cat:分类` 与 `-排除词` 复合检索语法，系统自动将限定词转化为精准过滤规则，消除匹配干扰。
- **搜索结果层次化分区呈现**：当混合召回常用语与全库思源块时，列表顶部展示 `📌 常用语资产 (N)`，下方展示 `🔍 思源全库匹配内容块 (N)` 专属吸顶分区头，界限分明，杜绝认知混乱。
- **外部直出双载荷（`plainText` & `richHtml`）**：`resolve()` 与 `recall()` 响应载荷中直接封装脱敏纯文本（自动剥离 Markdown 语法标记，微信/QQ 必备）与富文本 HTML（保留段落与加粗，Word/飞书/邮件 必备）。
- **全局可用脚本大全一键复制**：设置面板提供开箱即用的 AutoHotkey (AHK 全局热键直喷) 脚本、Quicker 动作配置与 cURL REST API 示例，实现任意外部窗口秒级上屏！
