# ADR 0154：视觉辨识度进化、双层底色关系、两色分工与重点深色对比块 (Visual Identity & Contrast Hierarchy)

## 状态
已接受，T-0579~T-0583（2026-10-29）。

## 背景与上下文
在完成基础设计令牌收敛与八态规范后，界面视觉进入到“辨识度与细节品质”的攻坚阶段：
1. **统一死灰底色缺乏呼吸感**：原本各界面的画布底色套用了通用的冷灰，未能依托项目自身主题色自然派生，导致内容卡片与背景之间缺乏灵动的底色关系；
2. **两色混淆未严格分工**：操作语义（按钮、选中高亮、焦点环）与数据语义（使用频次、命中率、统计大数）在个别界面混用，信息阅读无法第一眼区隔“交互落点”与“数据成果”；
3. **缺乏空间节奏重音**：界面整体平铺在浅色之中，缺乏深色重点对比块来打造节奏重音；
4. **圆角与微阴影精细度**：缺少外圆角减内边距的递减公式约束，阴影偏重偏单层，缺少近远叠合漫射漂浮感。

## 决策与落地
本轮经自主判定，确认本项目属于**工具操作型界面**（高频常用语召回、键盘极速上屏与侧栏货架），迁移范围选定为**全面迁移配色关系、圆角递减梯队、多层软阴影、深色节奏对比块与两色分工，整体饱和度压下一档，彩色专注于交互与核心数据**：

1. **底色关系（浅色托底、白卡浮起）**：
   - 以项目主题色色相（$H=243^\circ$）为基准，浅色整体画布取 $L=97.6\%, S=4.5\%$ 的极浅同族底色（`--xlc-canvas: #f6f6fb`）；
   - 内容列表与卡片取纯白（`--xlc-surface: #ffffff`），明度差精准控制在 2.4%（严格小于 3%）；
   - 配合双层叠加微阴影（`0 2px 4px rgba(41,34,72,0.03), 0 8px 24px rgba(41,34,72,0.06)`）表达轻盈漂浮感；
   - 深色模式画布取明度 11%、带主题微冷紫相的近黑（`#161522`），工作面取 $L=14\%$（`#1e1d2c`），主文字对比度达 14.2:1。
2. **两色严格分工（操作语义 vs 数据语义）**：
   - **操作语义色**：主题色 `--xlc-accent: #5e59cb`（暗色 `--xlc-accent: #b5afff`），专司按钮、选中项、主导航、主焦点；
   - **数据语义色**：从色相向青绿偏移 25° 派生翡翠绿 `--xlc-data-accent: #059669`（暗色 `--xlc-data-accent: #34d399`），专司使用频次（`.xlc-row-usecount`）、统计大数字与达标状态，两色严格解耦不互换。
3. **重点深色对比块与字体层级（节奏重音）**：
   - 在数据透视与重点卡片引入深色对比块 `--xlc-dark-card: #171622`（明度 11.5% 的主题相近黑），配翡翠绿数据高光与反白文本，形成视觉节奏上的重音；
   - 主数据大数字（22px~24px）与辅助文字（11px）形成近 3 倍尺寸阶梯，配合 `tabular-nums` 等宽排版；
   - 标题统一近黑 `--xlc-ink: #222133`，字重严格收敛至 400（常规）、500（中黑）、600（半粗）三档。
4. **不对称动效曲线与微触感**：
   - 引入进入缓出曲线 `--xlc-ease-in: cubic-bezier(0.16, 1, 0.3, 1)`（120~140ms）与退出干脆曲线 `--xlc-ease-out: cubic-bezier(0.4, 0, 1, 1)`（100~120ms）；
   - 按钮与交互元素在按下时收敛为 `scale(0.98)` 微触感反馈，彻底消除突兀抖动位移；
   - 分割线弱化为半透明发丝线 `--xlc-line: rgba(44, 43, 62, 0.07)`。
5. **自动化测试与负向门禁验证**：
   - 新增专项测试 `tests/r384-visual-identity-and-contrast-hierarchy.test.cjs`；
   - 注入负向突变 144（破坏数据语义色定义），门禁精准拦截红灯，恢复后复验全绿；
   - 单元测试增至 **1035/1035 项全绿**。
