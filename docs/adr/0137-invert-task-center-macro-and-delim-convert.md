# ADR 0137：Markdown待办状态反转、纯文本字宽居中对齐宏与分隔符智能嗅探互转 (Invert Task Status, Center Macro & Delimiter Conversion)

## 状态
已接受，T-0485~T-0489（2026-10-29）。

## 背景与上下文
在思源笔记内容资产的任务清单迭代、文本卡片居中排版以及多源列表分隔符规范化场景中，存在三类高频实用痛点：
1. **Markdown 任务列表项复选框勾选状态批量反转**：
   在周期性检查清单（如上线前检查单、行李清单）或敏捷冲刺复盘中，用户常常需要将已勾选的任务（`- [x]`）重置为未勾选（`- [ ]`），或将剩余未完成的任务一键翻转为已完成，或批量全选/全不选；
2. **纯文本按视觉宽度对称居中填充引擎与 `{{xlc:center}}` 动态宏**：
   在生成大纲分节标题、代码装饰框、Banner 横幅以及表格居中排版时，用户需要将字符在指定宽度（如 20 或 30 宽）内对称填充空格或特定符号（如 `=`、`-`），且必须精准支持中文字符双倍字宽计算；
3. **列表分隔符智能嗅探与批量互转引擎**：
   从各软件复制的数据往往分隔符各异（有的逗号分隔 `a, b, c`，有的分号 `a; b; c`，有的换行 `a\nb\nc`，有的管道符 `a|b|c`）。需要纯函数自动嗅探输入文本中最占优势的分隔符，并批量转换为目标分隔符（如将多行转换为逗号分隔，或逗号分隔转多行），并自动去除各元素边缘多余空白。

## 决策与落地
1. **Markdown 任务复选框状态智能反转引擎 (`invertTaskStatus`)**：
   - 纯函数实现，支持 `invert`（反转状态）、`check_all`（全勾选）与 `uncheck_all`（全取消）3 种模式；
   - 保护缩进、前缀标记及非任务行；
   - 动作菜单接线「🔄 反转任务待办勾选状态 ([ ] <-> [x]) 并复制」，表单格式栏接入「✦ 反转待办勾选」。
2. **纯文本字宽居中对齐与填充引擎 (`centerText`) 与 `{{xlc:center}}` 动态宏**：
   - 纯函数实现，计算 CJK 双倍字宽，左右对称补齐指定符号（默认空格）；
   - 扩展动态宏体系 `{{xlc:center|15|TITLE}}`、`{{xlc:center|15|TITLE|=}}`；
   - 动作菜单接线「📐 文本居中对齐填充至 30 宽度并复制」，表单格式栏接入「✦ 居中填充」，表单变量栏补充 `{{xlc:center|20|标题}}`。
3. **列表分隔符智能嗅探与批量互转引擎 (`convertListDelimiter`)**：
   - 纯函数实现，自动统计并选择出现频次最高的分隔符（支持显式指定），切分修剪元素后按目标分隔符重新组装；
   - 动作菜单接线「↔ 逗号与换行分隔符互转并复制」，表单格式栏接入「✦ 逗号换行互转」。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r363-inverttask-centermacro-and-delimconvert.test.cjs` 专项测试；

   - 源码恢复后复验全绿通过，单元测试总数达到 969/969 项。
