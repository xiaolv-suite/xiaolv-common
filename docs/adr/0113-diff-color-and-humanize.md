# ADR 0113：行级差异对比、色彩格式互转与标识符人类可读化宏 (Line Diff, Color Format Conversion & Identifier Humanization)

## 状态
已接受，T-0365~T-0369（2026-10-28）。

## 背景与上下文
在思源笔记内容资产层的高频复用与文本工程场景中，存在三类高频实用需求：
1. **常用语草稿与更新的快速行级差异对比**：
   在编辑长篇提示词模板、配置文件或条款草案时，用户需要快速对比当前编辑内容与原版本（或剪贴板内容）的行级变动（新增、删除、未变）；
2. **UI 设计与前端开发色彩格式互转**：
   在 CSS 样式、设计色板与代码模板中，HEX（如 `#1E88E5` / `#fff`）与 RGB/HSL 颜色代码之间的转换极其高频；
3. **技术变量标识符可读化重组**：
   在编写 API 文档、需求拆解与代码评审时，需要将驼峰（`getUserProfileById`）、下划线（`user_auth_token`）或短横线命名转换为人类自然阅读短语。

## 决策与落地
1. **多行文本行级差异对比引擎 (`diffLinesQuick`)**：
   - 纯函数实现，基于最长公共子序列（LCS）动态规划算法，直观输出未变行（`  `）、删除行（`- `）与新增行（`+ `）的统一差异清单；
   - 动作菜单接线「🔍 与当前条目草稿进行行级比对并复制」。
2. **色彩代码解析与格式互转引擎 (`convertColorFormat`) 与 `{{xlc:color}}` 动态宏**：
   - 纯函数实现，支持 3/6 位 HEX、RGB 与 HSL 之间的无损互转，非法字符串安全校验；
   - 扩展动态宏体系 `{{xlc:color:rgb|#ffffff}}` 与 `{{xlc:color|hex|rgb(0,0,0)}}`；
   - 动作菜单接线「🎨 颜色格式转换 (HEX ⇋ RGB) 并复制」，表单格式栏接入「✦ 转RGB色」，表单变量栏补充 `{{xlc:color:rgb|#336699}}`。
3. **变量标识符转人类可读自然短语引擎 (`humanizeIdentifier`)**：
   - 纯函数实现，自动分离连字符、下划线与驼峰边界，重组为首字母大写的自然单词短语；
   - 动作菜单接线「🔤 标识符转人类可读短语并复制」，表单格式栏接入「✦ 变短语」。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r339-diff-color-and-humanize.test.cjs` 专项测试；
   - 注入负向破坏行变动计数与颜色转换断言，确认两项负向测试均被精准拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 878/878 项。
