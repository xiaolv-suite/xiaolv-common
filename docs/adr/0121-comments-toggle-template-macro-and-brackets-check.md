# ADR 0121：代码多行注释批量切换、迷你模板插值宏与括号配对平衡校验 (Comments Toggling, Simple Template Interpolation & Brackets Balance Checking)

## 状态
已接受，T-0405~T-0409（2026-10-29）。

## 背景与上下文
在思源笔记内容资产层的高频使用与文本工程场景中，存在三类高频实用需求：
1. **多行代码或配置注释批量切换**：
   在技术记录、代码片段与配置草稿（JS/TS, Python, Shell, YAML, SQL）中，用户需要像在专业 IDE 中一样（如 `Ctrl + /`），对多行文本一键批量添加或移除注释符号，且需保留前置缩进与跳过空行；
2. **轻量变量插值迷你模板组装**：
   在客服话术、通知邮件与业务报备等场景中，经常存在结构简单的占位符模板（如 `{name}`、`{order_id}`、`{site}`），用户需要直接将模板与查询参数（`name=张三&order_id=101`）或 JSON 数据一键拼装为最终文本，并希望在动态宏中直接调用（`{{xlc:template|...}}`）；
3. **长文与技术公式中的括号闭合平衡性检查**：
   在编写复杂公式、JSON 嵌套、函数调用或公文标点时，经常因为输入遗漏产生未闭合的左括号或多余的右括号。用户需要一键诊断文本的标点括号成对平衡性，精确定位未闭合的括号类型。

## 决策与落地
1. **多行代码文本注释批量添加与移除引擎 (`toggleLineComments`)**：
   - 纯函数实现，自动侦测选中所有非空行是否均已带注释前缀：全带则切换为 `uncomment`，未全带则切换为 `comment`；
   - 保持行前置缩进（空格或 Tab），空行自动跳过；支持自定义前缀（`// `, `# `, `-- `, `; ` 等）；
   - 动作菜单接线「💬 批量切换代码行注释 (//) 并复制」，表单格式栏接入「✦ 切换注释」。
2. **字符串模板简单变量插值渲染引擎 (`renderSimpleTemplate`) 与 `{{xlc:template}}` 动态宏**：
   - 纯函数实现，兼容 `{key}` 与 `{{key}}` 占位符，数据层支持自动解析纯对象、JSON 字符串或 URL 查询字符串 / YAML 键值文本；
   - 扩展动态宏体系 `{{xlc:template|模板内容|数据内容}}`；
   - 动作菜单接线「📑 按 --- 分割渲染变量模板并复制」，表单格式栏接入「✦ 渲染模板」，表单变量栏补充 `{{xlc:template|你好 {name}|name=张三}}`。
3. **文本标点与括号闭合配对平衡性校验引擎 (`checkBracketsBalance`)**：
   - 纯函数实现，基于栈式结构严格校验 `()`, `[]`, `{}`, `《》`, `【】`, `「」`, `『』`, `“”` 的成对开闭；
   - 输出未闭合左括号清单 `unclosed` 与多余右括号清单 `unexpected` 及直观错误摘要；
   - 动作菜单接线「🔍 检测标点与括号闭合平衡性」，表单格式栏接入「✦ 检查括号」。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r347-comments-template-and-brackets.test.cjs` 专项测试；
   - 注入负向破坏注释模式切换判定与括号平衡检测结果，确认两项负向测试均被精准拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 909/909 项。
