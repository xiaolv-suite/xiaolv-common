# ADR 0103：多行文本前后缀剥离、键值对与 JSON 互转及隐私敏感信息掩码脱敏 (Affix Stripping, Properties-JSON Conversion & Sensitive Text Masking)

## 状态
已接受，T-0315~T-0319（2026-10-28）。

## 背景与上下文
在常用语管理与日常写作、开发、排版中，存在三类高频文本结构转换与数据隐私安全需求：
1. **列表与引用前缀逆向剥离需求**：
   在从 Markdown 文档或网页复制文本后，经常需要剔除行首的列表序号（`- `、`1. `、`① `）或引用前缀（`> `），恢复为纯文本段落；
2. **多语言配置 / Properties 文本与 JSON 数据互转**：
   在系统配置、国际化资源、Java `.properties` 与 API 参数维护中，用户需要将 `key = value` / `key: value` 快速转换为标准 JSON，或将 JSON 逆转为键值文本；
3. **客户服务与公开分享中的隐私信息脱敏**：
   在客服话术、对外分享常用模板、故障报告中，直接粘贴带有真实手机号、身份证号或电子邮箱的内容容易引发隐私泄露，需要自动化掩码脱敏能力与模板动态宏。

## 决策与落地
1. **多行文本前后缀自动剥离引擎 (`stripAffixes`)**：
   - 纯函数实现，支持预设模式 `list`（匹配 `- `、`* `、`+ `、数字点、圆圈数字等）与 `quote`（匹配 `> `）；
   - 支持自定义字符串与正则前后缀剥离，默认忽略空行；
   - 动作菜单接线「✂ 剥离列表/引用前缀并复制」，表单格式栏接入「✦ 剥前后缀」。
2. **Properties 键值对与 JSON 双向互转引擎 (`propertiesToJson`/`jsonToProperties`)**：
   - 纯函数实现，`propertiesToJson` 支持 `=` 与 `:` 分隔符，自动跳过空行与 `#`/`!` 注释行；
   - `jsonToProperties` 将 JSON 对象的顶层键值逆向转换为 `key=value` 多行文本；
   - 动作菜单接线「🌐 键值对转 JSON 并复制」，表单格式栏接入「✦ 键值转JSON」。
3. **隐私敏感信息智能掩码脱敏引擎 (`maskSensitiveText`) 与 `{{xlc:mask}}` 动态宏**：
   - 纯函数实现，采用前瞻与后顾边界正则 `(?<!\d)` / `(?!\d)`，严格防止身份证中的 11 位数字与手机号脱敏相互误伤；
   - 手机号（前3后4，中间4位 `****`）、身份证（前6后4，中间8位 `********`）、邮箱（保留首字母，其余到 `@` 前 `***`）；
   - 扩展动态宏 `{{xlc:mask|phone|...}}`、`{{xlc:mask|auto|...}}` 与冒号语法；
   - 动作菜单接线「🔒 敏感信息掩码脱敏并复制」，表单格式栏接入「✦ 敏感脱敏」，表单变量栏补充 `{{xlc:mask|phone|手机号}}`。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r329-affix-strip-and-mask.test.cjs` 专项测试；
   - 注入负向破坏前后缀剥离计数与掩码脱敏断言，确认两项负向测试均被精准拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 838/838 项。
