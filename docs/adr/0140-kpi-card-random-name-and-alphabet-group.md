# ADR 0140：Markdown核心指标KPI卡片生成、随机拟人姓名宏与首字拼音分节大纲 (KPI Card Generator, Random Name Macro & Alphabetical Grouping)

## 状态
已接受，T-0500~T-0504（2026-10-29）。

## 背景与上下文
在思源笔记常用内容资产的业务汇报看板、测试假数据生成及长清单字母表索引场景中，存在三类高频实用痛点：
1. **多行数据或键值对快速生成 Markdown 核心指标 KPI 看板卡片**：
   在编写会议纪要、运营周报、敏捷冲刺总结时，用户常常需要将若干项核心指标（如 `总营业额: 128500\n新增付费用户: 3420\n次日留存: 42.5%`）快速转为带边框卡片引用、加粗指标名与代码块数值的专业 Markdown 看板；
2. **拟人类随机中文/英文姓名生成引擎与 `{{xlc:randomname}}` 动态宏**：
   在编写用户故事（User Story）、测试用例原型数据、角色扮演模板或隐私脱敏客户演示时，用户需要生成拟真的中文姓名（如 `张伟`、`李娜`）或英文全名（如 `David Wilson`），并支持性别倾向；
3. **多行清单基于拼音/英文字母首字分节大纲引擎**：
   在梳理会员名单、客户通讯录、术语索引表或多源资源库时，列表长达数十上百行。用户需要按拼音首字母（A~Z）或英文首字母自动聚合并生成二级标题分节大纲（如 `## A\n- Apple\n\n## B\n- Banana\n- 菠萝`），并在组内按字典序排序。

## 决策与落地
1. **多行数据转 Markdown KPI 统计汇总卡片引擎 (`formatKpiSummaryCard`)**：
   - 纯函数实现，自动解析冒号、等号或 Markdown 表格行指标对；
   - 自动组装高管层视觉卡片表格，默认使用引用块包裹（`> `），指标名自动加粗，数值自动采用反引号标注；
   - 动作菜单接线「📊 生成 KPI 核心数据汇总看板并复制」，表单格式栏接入「✦ KPI看板」。
2. **拟人类随机姓名生成引擎 (`generateRandomName`) 与 `{{xlc:randomname}}` 动态宏**：
   - 纯函数实现，内置 30 大常见中文姓氏与常用男女名字符池，支持单名/双名智能随机；英文内置常见 First Name 与 Last Name 字典；
   - 扩展动态宏体系 `{{xlc:randomname}}`、`{{xlc:randomname:en}}`、`{{xlc:randomname:female}}`；
   - 动作菜单接线「👤 生成随机中文姓名并复制」，表单格式栏接入「✦ 随机姓名」，表单变量栏补充 `{{xlc:randomname}}`。
3. **多行文本基于拼音/字母首字分节大纲引擎 (`groupLinesByAlphabet`)**：
   - 纯函数实现，结合 `pinyin-tiny` 字符级引擎自动嗅探汉字声母拼音或拉丁首字母，按 A~Z 分组聚合生成大纲标题与条目清单；
   - 动作菜单接线「📑 按字母/拼音首字分节大纲并复制」，表单格式栏接入「✦ 首字字母分节」。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r366-kpicard-randomname-and-alphabetgroup.test.cjs` 专项测试；
   - 负向突变 111 破坏看板卡片输出，负向突变 112 破坏姓名生成输出，两项负向测试均被精确拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 978/978 项。
