# ADR 0139：Markdown引用块扁平化与剥离、单词逆序反转宏与行内格式标记批量剥离 (Flatten Blockquotes, Reverse Words Macro & Strip Inline Formatting)

## 状态
已接受，T-0495~T-0499（2026-10-29）。

## 背景与上下文
在思源笔记内容资产的多级排版净化、文本逆序分析与朗读/检索清洗场景中，存在三类高频实用痛点：
1. **Markdown 引用块层级混乱或多层嵌套剥离**：
   从邮件回复、网页或论坛复制的内容常带有多级乱序的引用符号（`>>> ...\n>> ...\n> ...`）。用户常常需要将其彻底转换为干净的无引用普通正文（`strip` 模式），或者将其全部收敛为单层标准引用（`single_level` 模式）；
2. **单词级别逆序反转引擎与 `{{xlc:revwords}}` 动态宏**：
   在语言学分析、文字倒装游戏、从后往前解析 token 或特定逆序模板排版中，用户需要词级别逆序（如 `the quick brown fox` -> `fox brown quick the`），区别于破坏单词内部拼写的逐字符反转（`reverseText`）；
3. **Markdown 行内样式标记批量剥离（纯文本净化）**：
   在准备将文案交由语音朗读（TTS）、全文轻量检索索引或向第三方无格式输入框粘贴时，用户需要纯函数一键剔除粗体（`**` / `__`）、斜体（`*` / `_`）、删除线（`~~`）、高亮（`==`）及行内代码（`` ` ``），同时严密保护代码中的下划线变量（如 `user_name`）不被误伤。

## 决策与落地
1. **Markdown 引用块扁平化与剥离引擎 (`flattenMarkdownBlockquotes`)**：
   - 纯函数实现，支持 `strip`（剥离所有 `>` 标记）与 `single_level`（将多层统一压缩为单层 `>`）2 种模式；
   - 动作菜单接线「💬 剥离所有引用符号 (>) 转为普通段落并复制」，表单格式栏接入「✦ 剥离引用」。
2. **单词级别逆序反转引擎 (`reverseWords`) 与 `{{xlc:revwords}}` 动态宏**：
   - 纯函数实现，按空格切分词汇并逆序组装，支持多行时保持各自行首缩进；
   - 扩展动态宏体系 `{{xlc:revwords|the quick brown fox}}`；
   - 动作菜单接线「🔄 单词级别逆序反转并复制」，表单格式栏接入「✦ 单词逆序」，表单变量栏补充 `{{xlc:revwords|the quick brown fox}}`。
3. **Markdown 行内样式标记批量剥离引擎 (`stripInlineMarkdownFormatting`)**：
   - 纯函数实现，剔除行内粗斜体、删除线、高亮及代码标记，保护代码变量中的孤立下划线；
   - 动作菜单接线「🧹 剥离行内加粗、斜体与代码标记并复制」，表单格式栏接入「✦ 剥离行内标记」。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r365-flattenquote-revwords-and-stripinline.test.cjs` 专项测试；
   - 负向突变 109 破坏引用剥离输出，负向突变 110 破坏单词逆序逻辑，两项负向测试均被精确拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 975/975 项。
