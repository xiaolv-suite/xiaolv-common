# ADR 0157：CSV/TSV 字段映射向导闭环、动态列选项与智能初次推断 (CSV/TSV Wizard Closure & Auto Infer)

## 状态
已接受，T-0597~T-0601（2026-10-30）。

## 背景与上下文
在完成全链路对外承诺可用性审查与 UI 待办清零后，针对高价值的 CSV/TSV 外部表格批量导入向导进行了深入交互实测，排查到关键断点：
1. **下拉选项未动态填充**：向导创建了 6 个字段的映射 `<select>`，但未能依据解析出的表格首行动态生成 `<option>` 选项，导致界面呈现为空白下拉框，用户无法选择列映射；
2. **缺乏直观字段标签**：网格中裸露选择器缺乏中文业务标签（标题、正文、分类、标签、别名、链接），导致用户无法分辨各下拉框意图；
3. **初次粘入需手动多步操作**：用户粘贴表格文本后，向导解析出表格却默认保持全部不映射，用户必须额外手动寻找并点击“智能推断”按钮才能触发预览，增加了操作摩擦力。

## 决策与落地
1. **字段标签卡片化与动态 Options 构建 (`src/ui/csv-tsv-wizard.ts`)**：
   - 为 6 个映射字段（标题/正文/分类/标签/别名/链接）配备统一的标签头部与响应式网格容器；
   - 在表格解析后，根据 `grid[0]`（表头列数与名称）动态注入 `<option value="-1">（不映射）</option>` 及 `<option value="i">第 i+1 列 (列名)</option>`。
2. **智能表头识别与初次自动推断联动**：
   - 监听文本粘贴输入后，若检测到所有映射字段处于初始未设定状态且表格行数大于 0，向导自动联动 `inferColumnMapping(grid)` 完成初次智能识别；
   - 用户粘完表格立等可预览前 5 行解析条目，显著降低心流阻力。
3. **样式对齐与微阴影卡片化 (`src/styles/index.scss`)**：
   - 为向导映射网格补充 `.xlc-wizard-mapping-row` 与 `.xlc-wizard-field-item` 现代白卡浮动样式，对齐 R187 设计令牌体系。
4. **自动化测试与负向门禁验证**：
   - 新增专项测试 `tests/r387-csv-wizard-closure.test.cjs`；
   - 注入负向突变 147（破坏列选项表头名称解析），门禁精准拦截红灯，恢复后复验全绿；
   - 单元测试增至 **1043/1043 项全绿**。
