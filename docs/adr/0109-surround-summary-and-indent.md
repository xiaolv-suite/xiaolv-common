# ADR 0109：多行双边对称包裹、精要摘要提取与代码缩进转换宏 (Line Surrounding, Executive Summary & Indentation Conversion)

## 状态
已接受，T-0345~T-0349（2026-10-28）。

## 背景与上下文
在常用语管理与日常写作、开发、排版中，存在三类高频文本处理需求：
1. **多行文本快速添加对称括号、引号或列表标记**：
   在把多行文本转换为代码数组（如每行加双引号 `"${line}"`）、粗体列表（`- **${line}**`）、书名号（`《${line}》`）时，手工逐行添加双侧标记极其耗时；
2. **长篇文档首段核心精要摘要快速生成**：
   在大型常用语、SOP 流程、技术方案中，用户经常需要生成一段适合在列表或卡片中快速浏览的精简摘要（提取首段有效非标题文本，剥离 Markdown 与多余换行，安全截取不超过指定长度）；
3. **代码与配置文件缩进不一致**：
   在跨平台复用代码或模板时，2/4 空格与制表符 Tab 之间的不一致经常导致排版错乱，需要精准的前置缩进转换能力。

## 决策与落地
1. **多行文本成对双边对称包裹引擎 (`surroundEachLine`)**：
   - 纯函数实现，自动识别括号对（`()`、`[]`、`{}`、`《》`、`【】`、`“”`）与自定义元组标记；
   - 默认忽略空行，支持行首尾预清理；
   - 动作菜单接线「🔄 多行双边双引号包裹并复制」，表单格式栏接入「✦ 双边包裹」。
2. **文本精要摘要提炼引擎 (`extractExecutiveSummary`) 与 `{{xlc:summary}}` 动态宏**：
   - 纯函数实现，跳过大标题与水平分割线，提取首个有效段落并剥离 Markdown 语法标记；
   - 扩展动态宏体系 `{{xlc:summary|100|TEXT}}`；
   - 动作菜单接线「📑 提取精要摘要 (120字) 并复制」，表单格式栏接入「✦ 提精要」，表单变量栏补充 `{{xlc:summary|100|文本}}`。
3. **代码与文本前置缩进双向转换器 (`convertIndentation`)**：
   - 纯函数实现，支持 `spaces-to-tabs`（空格转制表符）与 `tabs-to-spaces`（制表符转空格）；
   - 严格仅处理行首缩进，保护文本内部空格不受影响；
   - 动作菜单接线「⇥ 缩进转换 (空格转Tab) 并复制」，表单格式栏接入「✦ 空格转Tab」。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r335-surround-summary-and-indent.test.cjs` 专项测试；
   - 注入负向破坏双边包裹结果与缩进转换断言，确认两项负向测试均被精准拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 862/862 项。
