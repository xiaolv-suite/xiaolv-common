# ADR 0116：键值对解析提取、多行按列排序与正则捕获组模板重组 (Key-Value Extraction, Column-based Sorting & Regex Group Formatting)

## 状态
已接受，T-0380~T-0384（2026-10-28）。

## 背景与上下文
在思源笔记内容资产层的高频使用与文本工程场景中，存在三类高频实用需求：
1. **键值对参数提取与解析**：
   在 URL 参数分析、API 调试、配置文件或结构化文本中，用户常需要快速提取其中某一键的值（如从 `name=Alice&age=28` 中提取 `name` 或从多行 `host: localhost\nport: 8080` 中提取 `port`）；
2. **多行列表按指定列进行数值/拼音排序**：
   在制表符、逗号或空格分割的多行多列列表（如花名册、成绩单、日志列表）中，需要按指定某一列（如第 2 列分数或第 1 列姓名）进行排序，并且需要支持数值真实大小排序（避免 `100` 排在 `9` 前面）、降序反转以及首行表头行锁定；
3. **基于正则多捕获组的高级格式化重组**：
   在数据规范化和模板组装中，简单单值提取或纯文本替换无法满足复杂需求。例如将 `2026-10-28` 按照 `(\d{4})-(\d{2})-(\d{2})` 填入自定义模板 `$1年$2月$3日`，或将 `张三 (13800000000)` 提取组装为 `联系人: $1, 手机: $2`。

## 决策与落地
1. **键值对提取与参数解析引擎 (`parseKeyValuePairs`/`extractKvValue`) 与 `{{xlc:kv}}` 动态宏**：
   - 纯函数实现，自动解析 `&` 连接的 URL 查询参数（自动处理 `?` 前缀与 URL 解码）与多行 YAML/Properties 文本（`:` 或 `=` 分隔）；
   - 支持大小写宽松回退匹配；
   - 扩展动态宏体系 `{{xlc:kv:key|query_text}}` 与 `{{xlc:kv|key|query_text}}`；
   - 动作菜单接线「🔑 解析 URL 查询串为换行键值对并复制」，表单格式栏接入「✦ 提键值」，表单变量栏补充 `{{xlc:kv:key|key=value}}`。
2. **多行文本基于指定列排序引擎 (`sortLinesByColumn`)**：
   - 纯函数实现，支持指定列索引（从 1 开始计）；
   - 支持数值比较（`numeric: true`）、汉字拼音与字母字典序比较、降序反转（`descending: true`）以及表头保留（`hasHeader: true`）；
   - 动作菜单接线「📊 按第 1 列对多行数据排序并复制」与「📊 按第 2 列数值/字典序对多行排序并复制」，表单格式栏接入「✦ 按列排序」。
3. **正则多捕获组重组与格式化替换引擎 (`formatByRegexGroups`) 与 `{{xlc:match}}` 动态宏**：
   - 纯函数实现，基于正则表达式与捕获组参数（`$1`, `$2`, `$0`）一键插值到目标模板中；
   - 扩展动态宏体系 `{{xlc:match|pattern|template|text}}` 与 `{{xlc:match:pattern|template|text}}`；
   - 动作菜单接线「📅 重构日期为中文格式 (YYYY年MM月DD日) 并复制」，表单格式栏接入「✦ 正则重组」，表单变量栏补充 `{{xlc:match|(\\d+)|[$1]|123}}`。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r342-kv-sortcol-and-regexmatch.test.cjs` 专项测试；
   - 注入负向破坏数值排序判定逻辑与正则模板插值，确认两项负向测试均被精准拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 890/890 项。
