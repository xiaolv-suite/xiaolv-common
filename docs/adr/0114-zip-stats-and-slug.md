# ADR 0114：多行文本两两配对、高级统计指标与 Slug 别名生成宏 (Line Zipping, Advanced Statistics & Slug Conversion)

## 状态
已接受，T-0370~T-0374（2026-10-28）。

## 背景与上下文
在思源笔记内容资产层的高频使用与文本工程场景中，存在三类高频实用需求：
1. **两组多行列表配对合并**：
   在把两组列表（如一组“英文键名”，一组“中文描述”；或一组“姓名”，一组“电话号码”）按行进行两两交替拼接时，用户经常需要将两个列表一一对应合并为 `A1: B1` 或交替换行；
2. **高级数值统计（中位数、方差、标准差）**：
   在实验数据、财务指标、量化评估等模板中，除了基本的求和与平均值外，中位数（`median`）、方差（`variance`）与标准差（`stdDev`）是衡量数据离散度的核心统计指标；
3. **标题与短语转换为 URL/Git 安全别名**：
   在生成文档 URL 路径（Slug）、Git 分支名、博客文件名（如 `10 Tips for Better Code` -> `10-tips-for-better-code`）时，需要纯函数将任意标题安全转换为紧凑短横线别名。

## 决策与落地
1. **多行文本两两配对与交替合并引擎 (`zipLines`)**：
   - 纯函数实现，支持两行同行拼接（`inline`）与两行交叉换行（`alternate`）；
   - 支持自定义键值连接分隔符（默认 `: `）；
   - 动作菜单接线「🔗 前半段与后半段多行两两配对并复制」。
2. **高级统计指标计算引擎 (`calculateStats`) 与 `{{xlc:stats}}` 动态宏**：
   - 纯函数实现，自动提取输入字符串中的全部数值，计算样本总和、均值、中位数（`median`，偶数样本平滑取均值）、方差与标准差；
   - 扩展动态宏体系 `{{xlc:stats|10, 20, 30, 40, 50}}` 与取单个指标子命令 `{{xlc:stats:median|10, 50, 30}}`；
   - 动作菜单接线「🧮 高级统计分析 (中位数/方差) 并复制」，表单变量栏补充 `{{xlc:stats|10,20,30,40,50}}`。
3. **标题转 URL / Git 连字符别名引擎 (`slugifyText`)**：
   - 纯函数实现，保留字母数字、汉字与空格，将连续空白下划线换为中划线连字符（支持自定义分隔符与大小写保留）；
   - 动作菜单接线「🔗 转为 URL/Git 连字符别名 (Slug) 并复制」，表单格式栏接入「✦ 转Slug」。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r340-zip-stats-and-slug.test.cjs` 专项测试；
   - 注入负向破坏双行配对与方差计算断言，确认两项负向测试均被精准拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 882/882 项。
