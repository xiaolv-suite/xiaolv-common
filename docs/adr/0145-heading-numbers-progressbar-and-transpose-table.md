# ADR 0145：Markdown标题层级序号编排剥离、任务进度条宏与表格行列转置 (Heading Numbers, Progress Bar Macro & Transpose Table)

## 状态
已接受，T-0525~T-0529（2026-10-29）。

## 背景与上下文
在思源笔记长篇文档编目排版、任务进展可视化度量以及表格数据维度分析场景中，存在三类高频实用痛点：
1. **Markdown 多级标题层级数字序号自动编排与剥离**：
   在撰写学术论文、技术规范或项目方案时，各级标题（`#` ~ `######`）通常需要符合出版规范的十进制递增编号（如 `1. 绪论`、`1.1 研究背景`、`1.1.1 现状分析`）。人工手写序号极易在插入或调整段落后导致断号重排灾难；在对外分发或生成目录时又常需一键将序号剥离还原。
2. **任务完成进度可视化条图生成器与 `{{xlc:progress}}` 动态宏**：
   在日常项目周报、OKR 追踪、SOP 执行卡片中，用户强烈需要直观呈现进度状态，如方块进度条 `[███████░░░] 7/10 70%`、圆点进度 `[●●●○○] 60%` 或 ASCII 箭头 `[===>      ] 40%`，并在模板中以 `{{xlc:progress|7|10}}`、`{{xlc:progress|75}}` 动态展开；
3. **Markdown 表格矩阵行列转置（行转列与列转行）**：
   从系统导出或网页复制的 Markdown 表格通常是横向维度，而在笔记展示或移动端阅读时往往需要转换为纵向维度（原第一行表头转为第一列属性名，原各数据行转为后续各列）。用户需要纯函数无损转置表格矩阵，自动维护表头对齐分隔线（`:---`），支持空单元格安全补齐，并满足二次转置完全还原（$M^{TT} = M$）。

## 决策与落地
1. **Markdown 标题层级序号自动编排与剥离引擎 (`numberMarkdownHeadings`)**：
   - 纯函数实现，支持十进制层级自动计数（如 `1.`、`1.1`、`1.1.1`），支持自定义末尾点号与生效起止层级；
   - 严格识别并跳过代码围栏（```` ``` ```` 或 `~~~`），避免代码块中的 `#` 注释被误作为标题编号；
   - 支持 `mode: "strip"` 一键安全剥离多级数字序号；
   - 动作菜单接线「🔢 为各级标题编排递增层级序号并复制」与「🧹 一键剥离标题层级数字序号并复制」；表单格式栏接入「✦ 标题编序号」与「✦ 标题剥序号」。
2. **Unicode/ASCII 任务进度条度量生成器 (`formatTaskProgressBar`) 与 `{{xlc:progress}}` 动态宏**：
   - 纯函数实现，支持基于完成数/总数或直接百分比度量；
   - 支持 `block`（方块）、`circle`（圆点）与 `ascii`（箭头）三种排版视觉形态；
   - 智能宽度自适应：当未显式指定宽度且总数 $\le 20$ 时自动对齐元素总数（如 5 项渲染 5 个圆点 `●●●○○`）；
   - 扩展动态宏体系 `{{xlc:progress|7|10}}`、`{{xlc:progress:circle|3|5}}`、`{{xlc:progress|75}}`；表单变量栏补充 `{{xlc:progress|7|10}}`，格式栏接入「✦ 插入进度条」。
3. **Markdown 表格矩阵行列转置引擎 (`transposeMarkdownTable`)**：
   - 纯函数实现，解析 Markdown 表格行与单元格，执行矩阵行列翻转；
   - 自动识别并剥离原有分隔行，并在新表头下方重新插入对齐分隔行；
   - 支持非等长列缺失单元格以空串自动平齐；
   - 动作菜单接线「🔄 转置 Markdown 表格行列并复制」，表单格式栏接入「✦ 表格行列转置」。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r371-headingnumbers-progressbar-and-transposetable.test.cjs` 专项测试；
   - 负向突变 121 破坏标题编号输出逻辑，负向突变 122 破坏进度条方块字符生成逻辑，负向突变 123 破坏表格转置矩阵索引逻辑，三项负向测试均被精确拦截；
