# ADR 0112：多行表格行列转置、数字转英文单词与英文缩写展开宏 (Table Transposition, Number Words & Contractions Expansion)

## 状态
已接受，T-0360~T-0364（2026-10-28）。

## 背景与上下文
在思源笔记内容资产层的高频复用与文本工程场景中，存在三类高频实用需求：
1. **表格与多行记录行列转置倒置**：
   在把制表符或逗号分隔的多行数据从横向记录转为纵向、或将纵向指标转为横向表头时（如 Excel 中的“转置”粘贴功能），用户经常需要在多行多列的行列互换中来回折腾；
2. **数字转换为标准英文拼写单词**：
   在国际商务合同、涉外发票大写、技术文档条目计数（如 `42` -> `forty-two`, `100` -> `one hundred`）中，数字到英文词态转换是高频工具；
3. **英文日常缩写展开为正式公文词态**：
   在将口语化聊天记录、客服答复转化为正式商务邮件或学术文案时，经常需要将缩写展开（如 `don't` -> `do not`, `can't` -> `cannot`, `I'm` -> `I am`）。

## 决策与落地
1. **多行多列表格行列转置与矩阵倒置引擎 (`transposeMatrixText`)**：
   - 纯函数实现，自动解析制表符、逗号或竖线切分，自适应对齐不规则矩阵并完成行列互换对调；
   - 动作菜单接线「🔄 多行多列表格行列转置并复制」，表单格式栏接入「✦ 表格转置」。
2. **数字转英文大写拼写单词引擎 (`numberToEnglishWords`) 与 `{{xlc:words:en}}` 动态宏**：
   - 纯函数实现，支持百、千、百万、十亿分节解析与负数处理，输出自然流畅的英文单词串；
   - 扩展动态宏体系 `{{xlc:words:en|100}}`；
   - 动作菜单接线「🔤 数字转英文拼写单词并复制」，表单变量栏补充 `{{xlc:words:en|42}}`。
3. **英文日常缩写展开为正式公文形态引擎 (`expandEnglishContractions`)**：
   - 纯函数实现，覆盖数十种高频英文口语缩略词态（`can't`, `won't`, `didn't`, `it's`, `let's` 等），保持首字母大小写一致性；
   - 动作菜单接线「📝 英文日常缩写展开为正式词态并复制」，表单格式栏接入「✦ 展开缩写」。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r338-transpose-numwords-and-contractions.test.cjs` 专项测试；
   - 注入负向破坏表格转置首行与数字单词拼写断言，确认两项负向测试均被精准拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 874/874 项。
