# ADR 0138：Markdown脚注编号重整底端归集、反斜杠转义宏与分割线分段归集 (Markdown Footnotes Normalization, Slash Escape Macro & Line Chunks)

## 状态
已接受，T-0490~T-0494（2026-10-29）。

## 背景与上下文
在思源笔记长文撰写、跨源学术摘录与多段文档归集整理场景中，存在三类高频实用痛点：
1. **Markdown 脚注编号混乱与定义行分散**：
   从各处收集整理的学术笔记、图书书摘或长篇文章常包含大量 Markdown 脚注（`[^1]`、`[^note]` 以及对应的定义 `[^1]: 解释`）。由于碎片化复制，脚注编号常常断裂不连续（如跳跃的 `[^99]`），且脚注定义行常常混杂在正文中间。需要纯函数自动将正文脚注引用重编号为 `[^1]`, `[^2]`, `[^3]`...，并把所有对应定义行规范归集到文章最底部；
2. **反斜杠安全转义与还原引擎与 `{{xlc:slash}}` 动态宏**：
   在编写包含 Windows 文件路径（`C:\Users\...`）、正则表达式字面量或代码转义序列的模板时，反斜杠 `\` 极易在各层解析中被当作逃逸字符剥离破坏。用户需要纯函数与动态宏支持安全的双反斜杠转义（`\\`）与还原；
3. **多行文本基于水平分割线智能分段与标题聚合**：
   在整理对话记录、会谈纪要、阶段日志或多主题笔记时，内容常用分割线（`---` 或 `===`）隔开。需要纯函数自动按分割线将文本拆分为独立逻辑块，并自动为各段分配小标题（如 `### 分段 1\n...`）。

## 决策与落地
1. **Markdown 脚注编号重整与底端归集引擎 (`normalizeMarkdownFootnotes`)**：
   - 纯函数实现，提取正文全部定义与引用，按正文出现顺序重排为从 1 开始严格自增的数字序号；
   - 彻底剥离正文内部插入的脚注定义行，整齐追加归集在文档末尾（包含未被引用的孤立定义）；
   - 动作菜单接线「📑 重整 Markdown 脚注编号并底端归集并复制」，表单格式栏接入「✦ 规整脚注」。
2. **字符串反斜杠安全转义与还原引擎 (`escapeBackslash`) 与 `{{xlc:slash}}` 动态宏**：
   - 纯函数实现，支持转义模式（`\` -> `\\`，换行符与制表符编码）与反转义模式；
   - 扩展动态宏体系 `{{xlc:slash|C:\Users}}`、`{{xlc:slash:unescape|C:\\Users}}`；
   - 动作菜单接线「🛡 转义反斜杠 (\\ -> \\\\) 并复制」，表单格式栏接入「✦ 转义反斜杠」，表单变量栏补充 `{{xlc:slash|C:\\Users}}`。
3. **多行文本按标记分块归集引擎 (`chunkLinesByDelimiter`)**：
   - 纯函数实现，自动按水平分割线模式切分长文，修剪各分块边缘空白，支持自定义前缀生成结构化小标题；
   - 动作菜单接线「📑 按分割线将多行分块归集并复制」，表单格式栏接入「✦ 分割线分段」。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r364-footnotes-slashmacro-and-linechunks.test.cjs` 专项测试；
   - 负向突变 107 破坏脚注规整输出，负向突变 108 破坏反斜杠转义逻辑，两项负向测试均被精确拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 972/972 项。
