# ADR 0111：多行指定列提取、加权随机抽取与英文单复数转换宏 (Column Extraction, Weighted Choice & Pluralization)

## 状态
已接受，T-0355~T-0359（2026-10-28）。

## 背景与上下文
在思源笔记内容资产层的高频复用与文本工程场景中，存在三类高频实用需求：
1. **多行数据按列提取指定字段**：
   在处理日志、TSV/CSV 导出数据或带有固定分隔符的多行清单时，用户经常需要只提取其中的第 N 列（如只提取 ID 列或名称列）；
2. **话术与提示词加权概率随机抽取**：
   在客服话术 A/B 测试、多套文案轮换、游戏抽卡或 Prompt 随机选择中，等概率的 `random` 无法满足场景需求，需要支持带权重标记（如 `高频:70, 低频:30`）的轮盘赌概率抽取；
3. **英文单词单复数规则双向转换**：
   在编写代码模型实体、数据库表名（`user` -> `users`）、RESTful 路由及英文技术模板时，单复数转换频繁。

## 决策与落地
1. **多行文本指定列数据提取引擎 (`extractColumnFromLines`)**：
   - 纯函数实现，支持按列号（1-based）提取指定列数据，支持制表符、逗号、竖线或空格切分；
   - 自动过滤空行并对单元格内容进行预去空白处理；
   - 动作菜单接线「📑 提取多行第 1 列并复制」，表单格式栏接入「✦ 提首列」与「✦ 提次列」。
2. **加权随机概率抽取引擎 (`pickWeightedOption`) 与 `{{xlc:choose}}` 动态宏**：
   - 纯函数实现，解析 `选项:权重` 语法，基于累积概率分布实现轮盘赌加权抽样；
   - 扩展动态宏体系 `{{xlc:choose|VIP:70, 普通:30}}`；
   - 动作菜单接线「🎲 加权随机抽取一项并复制」，表单变量栏补充 `{{xlc:choose|VIP:70,普通:30}}`。
3. **英文单词单复数规则转换引擎 (`pluralizeText`)**：
   - 纯函数实现，支持不规则名词（`child/children`, `person/people`, `life/lives` 等）及常见词尾规则（`-s`, `-es`, `-ies`, `-ves`）双向互转；
   - 保持单词首字母大小写一致性；
   - 动作菜单接线「🔤 单词转复数 (Plural) 并复制」与「🔤 单词转单数 (Singular) 并复制」，表单格式栏接入「✦ 转复数」。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r337-column-extract-choose-and-plural.test.cjs` 专项测试；
   - 注入负向破坏第 1 列提取与复数转换断言，确认两项负向测试均被精准拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 870/870 项。
