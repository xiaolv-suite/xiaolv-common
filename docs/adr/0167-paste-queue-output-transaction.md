# ADR 0167：连续取用在输出确认后提交出队

日期2026-11-09。对应CY-001/CY-002及T-0852/T-0853。

连续取用是用户尚未完成的输入序列。快捷键和协议统一调用`service/paste-queue.ts`，以队首对象为本次身份，忙碌时拒绝第二次输出；输出返回true后才移除同一队首。返回false、异常、目标编辑器失效均保留队首；输出期间用户换队列不删除新队首。编辑器捕获tracked target并在锁内核实，移动统一复制。输出未知不能假装成功；不做静默重试，用户须核对后决定再试。

本次仅改变内存队列行为，未新增侧车/私有JSON。手机行内按钮及可访问名称与现有复制降级一致。原版与故障注入在外部bundle验证，不在并发生产源码中临时回滚。
