# ADR 0123：Markdown标题层级升降、幂等行前后缀补齐与多行正则锚点宏 (Markdown Headings Shifting, Idempotent Affixes & Multiline Regex Macro)

## 状态
已接受，T-0415~T-0419（2026-10-29）。

## 背景与上下文
在思源笔记内容资产层的高频使用与文本工程场景中，存在三类高频实用需求：
1. **Markdown 结构化章节层级整体升降级**：
   在把现有模板或章节段落复制、嵌套到另一篇文档的子标题下时，用户常需要将整段 Markdown 中的所有标题（`# `, `## `, `### `）批量降低一级（如变成 `## `, `### `, `#### `），或反向提升一级，并需要严格约束在 H1~H6 合法区间内，保持普通正文不受影响；
2. **多行文本构造 SQL 列表或任务清单时的幂等前后缀补齐**：
   在构造 SQL `IN ('a', 'b', 'c')` 语句、构造字符串数组或 Markdown 待办清单时，经常需要对多行文本添加首尾包裹字符（如首部 `'`，尾部 `',` 或 `- [ ] `）。手工拼接容易在已有引号的行上产生重复；需要纯函数实现幂等补齐（已有前缀/后缀则不重复添加）；
3. **多行跨行正则行首/行尾锚点替换**：
   在数据批量清洗与宏展开中，目前 `{{xlc:regex|replace|...}}` 默认为单行全局匹配，无法在模板中便捷使用 `^` 与 `$` 针对多行文本的每行开头或结尾批量追加、重构内容。需要增强多行模式宏（`mreplace` / `multiline`）。

## 决策与落地
1. **Markdown 标题层级批量升高/降低引擎 (`shiftMarkdownHeadings`)**：
   - 纯函数实现，支持配置 `delta` 正负步长（`delta: 1` 降级，`delta: -1` 升级）；
   - 严格在 `minLevel`（默认 1）与 `maxLevel`（默认 6）内夹紧，保护普通正文行；
   - 动作菜单接线「📑 标题层级批量降一级 (H1->H2) 并复制」与「📑 标题层级批量升一级 (H2->H1) 并复制」，表单格式栏接入「✦ 标题降级」与「✦ 标题升级」。
2. **文本行幂等前后缀补齐引擎 (`ensureLineAffixes`)**：
   - 纯函数实现，支持前缀（`prefix`）与后缀（`suffix`）幂等检测，行首已有前缀或行尾已有后缀时不重复追加；
   - 支持空行自动跳过（`skipEmpty: true`）；
   - 动作菜单接线「🔤 每行补齐单引号与逗号 ('...',) 并复制」，表单格式栏接入「✦ 补单引号」。
3. **多行正则跨行锚点替换引擎 (`regexReplaceMultiline`) 与 `{{xlc:regex}}` 宏体系增强**：
   - 纯函数实现，默认赋予 `gm` 标志，使 `^` 匹配每行开头，`$` 匹配每行结尾；
   - 动态宏支持冒号子命令 `{{xlc:regex:mreplace|^|* |文本}}` 与管道参数 `{{xlc:regex|mreplace|$|,|文本}}`；
   - 动作菜单接线「📑 为多行文本每行行首补齐项目符号 (- ) 并复制」，表单格式栏接入「✦ 行首加序号」，表单变量栏补充 `{{xlc:regex:mreplace|^(\s*)|// |文本}}`。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r349-headings-affixes-and-multiregex.test.cjs` 专项测试；
   - 注入负向破坏标题升降逻辑与前后缀幂等防重检查，确认两项负向测试均被精准拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 917/917 项。
