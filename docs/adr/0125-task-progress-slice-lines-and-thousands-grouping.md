# ADR 0125：任务列表进度统计、行区间截取与千分位数值格式化 (Task Progress Calculation, Line Slicing & Thousands Grouping)

## 状态
已接受，T-0425~T-0429（2026-10-29）。

## 背景与上下文
在思源笔记内容资产层的高频使用与文本工程场景中，存在三类高频实用需求：
1. **Markdown 待办任务清单完成进度量化与进度条呈现**：
   在项目大纲、日常备忘或冲刺计划中，任务列表（`- [ ]` 与 `- [x]`）是核心结构。用户在复盘、向上汇报或生成周报时，常需要一键统计当前清单的进度数据（总任务数、已完成、完成百分比 `60%`，并输出紧凑美观的字符进度条 `[██████░░░░] 60%`）；
2. **长文与日志中特定标记区间的定向抽取**：
   在长文处理、会议纪要摘录或日志错误分析中，用户常需要从某个标记行（如 `<!-- START -->`）截取到另一个标记行（如 `<!-- END -->`），并且需要支持配置是否保留起止标记；
3. **财务金额与量化数值千分位规范化**：
   在财务报表、发票核对与量化报表中，数值常要求呈现为标准千分位分隔格式（如 `1,234,567.89`），且需在宏体系中方便调用（`{{xlc:thousands|...}}`），或反向将带逗号的格式化文本剥离为纯数字。

## 决策与落地
1. **Markdown 任务列表项进度计算与统计引擎 (`calculateTaskProgress`)**：
   - 纯函数实现，自动识别 `- [ ]`、`- [x]`、`* [X]`、`1. [ ]` 待办清单行；
   - 计算总数、已完成数、百分比并输出自适应长度字符进度条与摘要说明；
   - 动作菜单接线「📊 统计任务列表进度条并复制」，表单格式栏接入「✦ 任务进度」。
2. **文本行按起止标记条件截取引擎 (`sliceLinesByPattern`)**：
   - 纯函数实现，支持字符串子串或正则表达式匹配起止行，支持 `includeStart` 与 `includeEnd` 配置；
   - 动作菜单接线「📑 截取 START_LOG 至 END_LOG 区间并复制」，表单格式栏接入「✦ 截取区间」。
3. **千分位数值格式化与反格式化引擎 (`formatNumberGrouping`) 与 `{{xlc:thousands}}` 动态宏**：
   - 纯函数实现，严格保持正负号和小数部分完整，支持双向 `add`（加千分位）与 `remove`（剥离千分位）；
   - 扩展动态宏体系 `{{xlc:thousands|1234567.89}}` 与子命令 `{{xlc:thousands:clean|1,234,567.89}}`；
   - 动作菜单接线「￥ 数值添加千分位逗号并复制」与「￥ 剥离千分位逗号为纯数字并复制」，表单格式栏接入「✦ 加千分位」，表单变量栏补充 `{{xlc:thousands|1234567.89}}`。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r351-taskprogress-slicelines-and-thousands.test.cjs` 专项测试；
   - 注入负向破坏进度百分比计算与千分位逗号插入逻辑，确认两项负向测试均被精准拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 925/925 项。
