# ADR 0117：多行文本缩进/反缩进、数据格式规范性校验与 Markdown 表格行筛选 (Line Indentation, Format Validation & Markdown Table Filtering)

## 状态
已接受，T-0385~T-0389（2026-10-29）。

## 背景与上下文
在思源笔记内容资产层的高频使用与文本工程场景中，存在三类高频实用需求：
1. **多行列表与大纲文本层级缩进调整**：
   在整理大纲笔记、思维导图转文本、代码片段或嵌套列表时，用户常需要对选中的多行文本统一增加或减少一级缩进（如整体缩进 2 空格或 Tab），且需智能跳过纯空行；
2. **文本数据格式合法性校验**：
   在表单填写、模板参数传递、用户输入审查与自动化归档中，用户常需要判断输入的字符串是否符合常见数据规范（如邮箱、中国大陆手机号、IPv4 地址、URL 或纯数字），并根据合法与否动态输出布尔值或自定义反馈文案；
3. **Markdown 表格条件过滤与行列清洗**：
   从网页、数据库或任务报表复制出的 Markdown 表格常包含大量无效行、空值行或未完成行，用户需要根据某列的特定关键字或正则模式快速筛选出符合条件的数据行，并保持 Markdown 表头与分隔线的完整性。

## 决策与落地
1. **多行文本指定层级缩进与反向缩进引擎 (`indentLines`/`outdentLines`)**：
   - 纯函数实现，支持自定义步长（默认 2）与缩进字符（空格或 `\t`）；
   - 支持空行自动跳过（`skipEmpty: true`）；反缩进时支持按空格与 Tab 平滑扣减前缀；
   - 动作菜单接线「➡️ 多行整体增加 2 空格缩进并复制」与「⬅️ 多行整体反向减少 2 空格缩进并复制」，表单格式栏接入「✦ 增缩进」与「✦ 减缩进」。
2. **数据格式规范性校验引擎 (`validateFormat`) 与 `{{xlc:valid}}` 动态宏**：
   - 纯函数实现，支持 `email`, `phone`, `idcard`, `ipv4`, `url`, `number`, `date` 等 7 种高频数据类型；
   - 扩展动态宏体系 `{{xlc:valid:email|test@example.com}}`、`{{xlc:valid:phone|138...}}` 与带自定义文案语法 `{{xlc:valid|type|value|trueText|falseText}}`；
   - 动作菜单接线「✅ 校验是否为合法 email/phone/url 并复制」，表单格式栏接入「✦ 校验格式」，表单变量栏补充 `{{xlc:valid:email|test@example.com}}` 与 `{{xlc:valid:phone|13800000000}}`。
3. **Markdown 表格列条件过滤与行筛选引擎 (`filterMarkdownTable`)**：
   - 纯函数实现，按指定列（从 1 开始计）对数据行执行关键词匹配、正则表达式或判定函数校验；
   - 完整保留第一行表头与第二行分隔线，支持反向过滤排除匹配行（`invert: true`）；
   - 动作菜单接线「⊞ Markdown 表格按第 1 列排除空值行并复制」，表单格式栏接入「✦ 表格筛选」。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r343-indent-valid-and-tablefilter.test.cjs` 专项测试；
   - 注入负向破坏邮箱格式正则判定与 Markdown 表格表头保留逻辑，确认两项负向测试均被精准拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 894/894 项。
