# ADR 0144：Markdown标题与列表双向互转、词汇打乱宏与数值区间行过滤 (Headings to List, Shuffle Macro & Numeric Range Filter)

## 状态
已接受，T-0520~T-0524（2026-10-29）。

## 背景与上下文
在思源笔记内容资产的大纲结构重塑、随机抽样测验及带数值日志/报表数据清洗场景中，存在三类高频实用痛点：
1. **Markdown 多级标题与层级缩进列表双向互转**：
   在编写汇报 PPT 提纲、章节摘要或笔记结构重整时，用户常常需要将文章中多级标题（`#` ~ `######`）一键转换为按深度缩进的 Markdown 圆点列表（`- `），或反向将缩进列表还原为 H1~H6 大纲标题；
2. **列表词汇或行随机打乱引擎与 `{{xlc:shuffle}}` 动态宏**：
   在设计互动答题、背诵卡片、单词乱序测试或测试数据随机洗牌时，用户需要纯函数根据指定分隔符（换行、逗号、空格）对元素执行真正的 Fisher-Yates 随机打乱；
3. **多行数据基于提取数值的区间范围过滤**：
   在分析性能日志、服务器指标、报价单或工时记录时，每行记录中通常包含核心数值（如 `响应时间: 240ms`、`单价: 88元`）。用户需要快速筛选出数值位于指定区间（如 `>= 100` 或 `50 ~ 100`）的有效行，过滤无效噪声行。

## 决策与落地
1. **Markdown 标题与列表双向智能互转引擎 (`convertHeadingsToList`)**：
   - 纯函数实现，支持 `headings_to_list`（按相对层级转换为缩进圆点列表）与 `list_to_headings`（按缩进深度映射为相应级别标题）双向互转；
   - 动作菜单接线「📑 转换各级标题为嵌套缩进列表并复制」，表单格式栏接入「✦ 标题转列表」。
2. **列表词汇或行随机打乱引擎 (`shuffleList`) 与 `{{xlc:shuffle}}` 动态宏**：
   - 纯函数实现，自动嗅探换行或中英文逗号分隔符，执行标准 Fisher-Yates 均匀洗牌算法；
   - 扩展动态宏体系 `{{xlc:shuffle|A,B,C,D,E}}`、`{{xlc:shuffle:line|1\n2\n3}}`；
   - 表单变量栏补充 `{{xlc:shuffle|A,B,C}}`。
3. **多行数据数值区间筛选过滤引擎 (`filterNumericRangeLines`)**：
   - 纯函数实现，提取行内首个数值浮点数，支持最小阈值（`min`）、最大阈值（`max`）及反选（`invert`）；
   - 动作菜单接线「🔍 仅保留包含数值 >= 100 的行并复制」，表单格式栏接入「✦ 筛选>=100」。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r370-headingstolist-shufflemacro-and-numfilter.test.cjs` 专项测试；
   - 负向突变 119 破坏标题转列表逻辑，负向突变 120 破坏数值区间过滤逻辑，两项负向测试均被精确拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 990/990 项。
