# ADR 0110：多行数值提取汇总、农历干支生肖年份与高频重复词组检测宏 (Numeric Lines Summary, Chinese Lunar Year & Repeated Phrases)

## 状态
已接受，T-0350~T-0354（2026-10-28）。

## 背景与上下文
在思源笔记内容资产层的高频使用与文本工程场景中，存在三类高频实用需求：
1. **多行列表数值汇总与小计分析**：
   在报销发票清单、采购报价明细、工时打卡记录等常用文本中，多行每行都包含数值，用户需要一键统计合计、平均值与最大/最小值；
2. **中国传统农历干支纪年与生肖年份换算**：
   在节日祝福、合同文书签署、生肖纪年等常用模板中，公历年份（如 `2026`）与天干地支（如 `丙午年 (马年)`）的快速映射和宏展开属于文化刚需；
3. **文本啰嗦与高频重复词组自动检测**：
   在写作润色、文案核对、Prompt 提示词审查时，检查文本内部是否存在高频重复的短语（2~4 字），帮助提升表达精练度。

## 决策与落地
1. **多行文本数值提取与汇总求和引擎 (`sumNumericLines`)**：
   - 纯函数实现，自动提取多行文本中每行包含的有效金额与数值；
   - 快速计算总和（`sum`）、平均值（`average`）、有效记录笔数（`count`）与极值（`[min, max]`）；
   - 动作菜单接线「🧮 多行数值求和与统计并复制」，表单格式栏接入「✦ 数值求和」。
2. **农历天干地支与生肖年份推算引擎 (`getChineseZodiacAndStemBranch`) 与 `{{xlc:lunar}}` 动态宏**：
   - 纯函数实现，基于天干（十天干）、地支（十二地支）与十二生肖的周期推算算法，零额外依赖；
   - 扩展动态宏体系 `{{xlc:lunar:year}}` 与 `{{xlc:lunar|stembranch|2024}}`；
   - 动作菜单接线「🧧 公历年转干支生肖并复制」，表单变量栏补充 `{{xlc:lunar:year}}`。
3. **高频重复词组与短语检测分析器 (`extractRepeatedPhrases`)**：
   - 纯函数实现，基于 N-gram 滑动窗口自动分析文本中重复出现的 2~4 字词组（出现频次 ≥ 2）；
   - 动作菜单接线「🔎 检测高频重复词组短语并复制」，表单格式栏接入「✦ 查重复词」。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r336-numeric-lunar-and-phrases.test.cjs` 专项测试；
   - 注入负向破坏数值求和与农历干支断言，确认两项负向测试均被精准拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 866/866 项。
