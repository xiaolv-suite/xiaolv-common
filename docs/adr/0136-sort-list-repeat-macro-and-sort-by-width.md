# ADR 0136：Markdown列表项拼音自然排序、字符序列重复生成宏与文本行视觉宽度排序 (Sort Markdown List, Repeat Macro & Sort Lines by Visual Width)

## 状态
已接受，T-0480~T-0484（2026-10-29）。

## 背景与上下文
在思源笔记内容资产的清单整理、装饰分割线生成及文本排版展示场景中，存在三类高频实用痛点：
1. **Markdown 列表项按拼音或字母自然排序**：
   用户在梳理待办任务、书签清单、术语表或标签索引时，常常需要将无序（`- `）或有序（`1. `）列表按拼音字母自然升序（A-Z）或降序排列。排序时必须支持子列表整体联动随父级行位移，并在有序列表排序后自动连续重编号；
2. **字符与文本序列重复生成引擎与 `{{xlc:repeat}}` 动态宏**：
   在编写 Markdown 文本分割线（如 `====================` 或 `- - - - - `）、ASCII 装饰框或测试占位数据时，用户需要纯函数根据指定次数重复生成字符，并支持自定义分隔符与安全长度上限防卡死；
3. **多行文本按中英视觉宽度智能排序**：
   在诗歌排版、UI 菜单整理、徽标标签排列或视觉居中展示时，用户常常需要将多行文本按视觉宽度从短到长（或从长到短）排列。需精准计算 CJK 中文字符双倍字宽。

## 决策与落地
1. **Markdown 列表项按字母或拼音自然排序引擎 (`sortMarkdownList`)**：
   - 纯函数实现，将列表项组织为块结构，支持平级排序并携带嵌套子列表递归排序；
   - 有序列表自动连续自增重编号，支持升序与降序；
   - 动作菜单接线「📶 列表项按拼音/字母升序排序并复制」，表单格式栏接入「✦ 列表拼音排序」。
2. **字符与文本序列重复生成引擎 (`repeatText`) 与 `{{xlc:repeat}}` 动态宏**：
   - 纯函数实现，支持指定重复次数（最大 500 次）与总字符上限（最大 2000 字符），支持自定义分隔符；
   - 扩展动态宏体系 `{{xlc:repeat|=|20}}`、`{{xlc:repeat|*|5}}`、`{{xlc:repeat|8|#}}`；
   - 动作菜单接线「🔁 重复生成 20 次并复制」，表单格式栏接入「✦ 重复10次」，表单变量栏补充 `{{xlc:repeat|=|20}}`。
3. **文本行视觉宽度智能排序引擎 (`sortLinesByVisualWidth`)**：
   - 纯函数实现，计算 CJK 字符双倍字宽，支持按整行视觉宽度升序或降序排列；
   - 动作菜单接线「📐 多行文本按视觉宽度升序排列并复制」，表单格式栏接入「✦ 按长短排序」。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r362-sortlist-repeatmacro-and-sortbywidth.test.cjs` 专项测试；
   - 负向突变 103 破坏列表排序输出，负向突变 104 破坏重复字符逻辑，两项负向测试均被精确拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 966/966 项。
