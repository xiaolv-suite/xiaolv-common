# ADR 0124：代码语言智能嗅探、单词字符洗牌打乱与冗余标点压缩 (Code Language Detection, Text Scrambling & Repeated Chars Compacting)

## 状态
已接受，T-0420~T-0424（2026-10-29）。

## 背景与上下文
在思源笔记内容资产层的高频使用与文本工程场景中，存在三类高频实用需求：
1. **未标记语言的裸代码自动添加语言围栏**：
   在从聊天记录、报错日志、无语法高亮的网页或终端中复制一段代码时，用户常需要将这段代码快速收录为代码块，但手工输入语言名称（如 `json`, `python`, `sql`, `typescript`）繁琐且易出错。需要纯函数实现高置信度的语法特征与关键字嗅探引擎；
2. **教学背诵与记忆测试中的随机打乱洗牌**：
   在制作背诵卡片（如英语单词拼写打乱记忆、词组乱序连词成句）、密码学测试或生成测试乱序样本时，用户常需要将输入的句子按单词打乱（`words`）或将单词内部字母随机打乱（`chars`），并在宏展开中直接调用；
3. **复制评论或草稿中的连续冗余重复标点清洗**：
   从社交媒体、网页评论或聊天记录复制的内容常带有情绪化的连续标点（如 `！！！！`、`？？？？`、`~~~~~~`）。排版规范要求将连续多于一个的标点符号压缩为标准的一个或两个，保持视觉整洁。

## 决策与落地
1. **代码片段编程语言智能嗅探与推导引擎 (`detectCodeLanguage`)**：
   - 纯函数实现，覆盖 `json`, `sql`, `python`, `typescript`, `javascript`, `html`, `css`, `bash`, `rust`, `go`, `markdown` 等常见开发与标记语言；
   - 优先通过类型声明与特征语法区分 TypeScript 与 CSS，精准输出语言标识与置信度；
   - 动作菜单接线「💻 包装为指定代码块并复制」，表单格式栏接入「✦ 嗅探语言」。
2. **随机打乱文本字符与单词洗牌引擎 (`scrambleText`) 与 `{{xlc:scramble}}` 动态宏**：
   - 纯函数实现，基于 Fisher-Yates 算法对句子中的单词顺序或字符序列进行公平随机洗牌，安全支持 Unicode 字符；
   - 扩展动态宏体系 `{{xlc:scramble|words|...}}` 与 `{{xlc:scramble:chars|...}}`；
   - 动作菜单接线「🔀 随机打乱句子单词顺序 (洗牌) 并复制」，表单格式栏接入「✦ 单词洗牌」，表单变量栏补充 `{{xlc:scramble|words|one two three}}`。
3. **文本重复字符与冗余标点智能压缩引擎 (`compactRepeatedCharacters`)**：
   - 纯函数实现，利用 Unicode 标点与符号类正则 `[\p{P}\p{S}]` 识别连续相同标点，按指定上限（默认 1）智能收缩并返回压缩字符数；
   - 动作菜单接线「🧹 压缩冗余连续重复标点并复制」，表单格式栏接入「✦ 压重标点」。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r350-codelang-scramble-and-compactchars.test.cjs` 专项测试；
   - 注入负向破坏代码语言检测逻辑与重复标点压缩判定，确认两项负向测试均被精准拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 921/921 项。
