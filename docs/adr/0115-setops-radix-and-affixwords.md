# ADR 0115：多行文本集合运算、跨进制数值互转与代码词缀剥离 (Line Set Operations, Multi-Radix Conversion & Affix Stripping)

## 状态
已接受，T-0375~T-0379（2026-10-28）。

## 背景与上下文
在思源笔记内容资产层的高频使用与文本工程场景中，存在三类高频实用需求：
1. **多行列表集合运算（差集、并集、交集）**：
   在处理任务清单对比、差异排查、去重合并等数据处理场景中，用户经常需要对比两段列表（如通过 `---` 分割的列表 A 与列表 B），计算“在 A 中但不在 B 中”（差集 A - B）、“同时存在于 A 和 B 中”（交集 A ∩ B）或“合并两段并去重”（并集 A ∪ B）；
2. **跨进制数值互转与位对齐（BIN/OCT/DEC/HEX）**：
   在软件开发、嵌入式工程、网络协议与硬件调试笔记中，经常需要在十进制、十六进制（0x）、二进制（0b）与八进制（0o）之间互转，并需要支持补零位对齐（如 8 位 `00000101`）与大写前缀格式；
3. **代码变量前后缀（get_/is_/_id/Dto）批量剥离**：
   在把数据表字段转换为模型属性、重构代码接口名或制作中英文对照时，变量名往往带着冗余的方法前缀（`get_`, `set_`, `is_`, `has_`）或实体后缀（`_id`, `_ids`, `Dto`, `VO`），需要一键批量剥离。

## 决策与落地
1. **多行文本集合运算引擎 (`setOperationsOnLines`)**：
   - 纯函数实现，支持差集（`difference`, A - B）、交集（`intersection`, A ∩ B）与并集（`union`, A ∪ B）运算；
   - 支持大小写敏感度选项（`caseSensitive`）、首尾去空白（`trimLines`）与忽略空行（`ignoreEmpty`），保持 A 中元素的初始出现顺序；
   - 动作菜单接线「⊖ 前后两段列表多行求差集 (A - B) 并复制」与「∪ 前后两段列表多行求并集 (A ∪ B) 并复制」，表单格式栏接入「✦ 差集过滤」。
2. **跨进制数值互转与位对齐引擎 (`convertRadix`) 与 `{{xlc:radix}}` 动态宏**：
   - 纯函数实现，支持 2/8/10/16 任意跨进制数值互转；
   - 自动识别并剥离输入中的 `0x`/`0b`/`0o` 前缀，支持配置输出前缀、大写、以及指定位宽补零对齐（`padBits`）；
   - 扩展动态宏体系 `{{xlc:radix|255}}`、`{{xlc:radix:hex|255}}`、`{{xlc:radix:bin|42}}`、`{{xlc:radix|hex2dec|0x2A}}` 与 `{{xlc:radix:bin2dec|101010}}`；
   - 动作菜单接线「🔢 数值转十六进制 (DEC→HEX) 并复制」、「🔢 数值转二进制 (DEC→BIN) 并复制」与「🔢 十六进制转十进制 (HEX→DEC) 并复制」，表单格式栏接入「✦ 转十六进制」，表单变量栏补充 `{{xlc:radix:hex|255}}` 与 `{{xlc:radix:bin|42}}`。
3. **代码变量词缀批量剥离与提取引擎 (`stripAffixWords`)**：
   - 纯函数实现，支持字符串或正则模式配置前缀（`prefix`）与后缀（`suffix`）；
   - 动作菜单接线「✂ 批量剥离常见代码词缀 (get_/is_/_id/Dto) 并复制」，表单格式栏接入「✦ 剥离词缀」。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r341-setops-radix-and-affixwords.test.cjs` 专项测试；
   - 注入负向破坏多行差集过滤逻辑与十六进制前缀拼接，确认两项负向测试均被精准拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 886/886 项。
