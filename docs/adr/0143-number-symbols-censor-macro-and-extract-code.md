# ADR 0143：数字圈号序号互转、敏感词遮罩过滤宏与Markdown纯代码块提取 (Number Symbols, Censor Macro & Extract Code Blocks)

## 状态
已接受，T-0515~T-0519（2026-10-29）。

## 背景与上下文
在思源笔记内容资产的条款序号编排、敏感文案过滤及技术文档代码提取场景中，存在三类高频实用痛点：
1. **数字与圈号、括号特殊序号符号双向互转**：
   在法律条款、合同步骤、论文要点排版中，用户经常需要将普通阿拉伯数字 `1~20` 批量转为圈号符号（`①`, `②`...`⑳`）或带括号序号（`⑴`, `⑵`...`⒇`），或在复制外部文本时反向还原为标准阿拉伯数字，手动查找替换耗时费力；
2. **敏感词与屏蔽词动态遮罩引擎与 `{{xlc:censor}}` 动态宏**：
   在公开分享笔记、社区发言、测试脱敏或内容发布时，用户常常需要将特定黑名单关键词、敏感词或指定正则进行遮罩替换（如替换为 `***`、`[REDACTED]` 或等长星号 `*`）；
3. **Markdown 纯代码块提取与正文剥离**：
   阅读开发教程、技术博客或架构说明时，文档通常穿插着大量文字解释与说明配图。用户往往仅需要快速提取出其中的可运行脚本代码（可按语言如 `python`、`typescript` 过滤），过滤一切文字段落，便于在终端或 IDE 中一键粘贴调试。

## 决策与落地
1. **文本字符集与数字格式互转引擎 (`convertNumberSymbols`)**：
   - 纯函数实现，支持 `circled`（圈号 ①~⑳）、`bracketed`（括号序号 ⑴~⒇）与 `digits`（普通阿拉伯数字）3 种目标模式；
   - 动作菜单接线「① 序号数字转圈号 (1 -> ①) 并复制」与「🔢 圈号数字转普通阿拉伯数字并复制」，表单格式栏接入「✦ 转圈号数字」。
2. **敏感字符遮罩与屏蔽词过滤引擎 (`censorText`) 与 `{{xlc:censor}}` 动态宏**：
   - 纯函数实现，支持单词、数组或逗号分隔关键词列表，自动转义特殊正则元字符并支持等长星号遮罩；
   - 扩展动态宏体系 `{{xlc:censor|文本|敏感词|***}}`、`{{xlc:censor:mask|文本|敏感词}}`；
   - 表单变量栏补充 `{{xlc:censor|文本|敏感词|***}}`。
3. **Markdown 代码块提取与正文拆分引擎 (`extractCodeBlocksFromMarkdown`)**：
   - 纯函数实现，状态机精准识别开闭围栏，提取内部纯代码，支持 `languageFilter` 指定特定编程语言，支持追加语言头部注释；
   - 动作菜单接线「💻 仅提取所有代码块并复制」，表单格式栏接入「✦ 提取纯代码」。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r369-numsymbols-censormacro-and-extractcode.test.cjs` 专项测试；
   - 负向突变 117 破坏圈号转换输出，负向突变 118 破坏敏感词屏蔽逻辑，两项负向测试均被精确拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 987/987 项。
