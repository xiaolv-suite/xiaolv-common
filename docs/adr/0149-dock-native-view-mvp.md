# ADR 0149：侧边栏 (Dock) 原生常驻视图 MVP、拖拽上屏与常驻货架 (Native Dock View MVP & Drag-and-Drop)

## 状态
已接受，T-0549~T-0553（2026-10-29）。

## 背景与上下文
「小驴常用」此前主要依赖居中模态弹窗（`Dialog` / Launcher）作为主要的调用与交互方式。
虽然快捷键呼出弹窗具备极高的时间效率，但在长文撰写、日常多轮客服答复、代码审查或边写边查阅多条常用资产等场景中，居中模态弹窗会遮挡编辑器主工作区，反复打开和关闭打断了连续沉浸的写作心流。

用户提出需求：立即进入**阶段 1（MVP 基础常驻视图）**的技术设计与实现，在思源笔记右侧 Dock 栏常驻一个极简高密度的内容资产货架，与快捷弹窗互补。

## 决策与落地
1. **Dock 面板视图控制器 (`src/ui/dock-view.ts`)**：
   - 专为 240px~360px 单列纵向空间打造紧凑布局；
   - 顶栏：标题、新建条目按钮（`＋`）、刷新按钮（`↺`）、设置面板入口（`⚙`）；
   - 紧凑搜索栏：支持中文拼音/首字母实时过滤与清空按钮；
   - 过滤胶囊栏：全部（All）、常用（Common，按频次自适应降序）、最近（Recent）、★ 收藏（Favorites）；
   - 紧凑单列列表：条目类型鲜艳微标、单行标题与别名，鼠标悬停浮现快捷操作（`＋` 插入并保护光标、`⧉` 复制纯文本、`★` 收藏切换）；
   - 原生 HTML5 拖拽落块支持（`draggable = true`）：监听 `dragstart` 并封装纯文本与 Markdown 载荷，用户可直接按住条目拖入正文落块；
   - 底部微型抽屉：单击行在底部展开即时抽屉预览（复用 `previewRenderer`），提供主插入与复制按钮。
2. **官方宿主契约与生命周期 (`src/index.ts`)**：
   - 调用官方 `this.addDock` 接口，默认注册至 `RightTop`（右上侧栏），配置尺寸 `{ width: 300, height: 0 }` 与图标 `iconXlcCommon`；
   - 注册全局快捷切换命令 `xiaolv.common.toggleDock`（快捷键 `⌥⇧D`）；
   - 移动端检测（`this.host.isMobile()`）诚实优雅降级，移动端不生成桌面 Dock 冗余节点；
   - 插件卸载（`onunload`）时严格执行 `dockView.destroy()`，释放 DOM 与事件定时器，零内存泄漏。
3. **双向无感差量广播机制 (`notifyExternalDataChange`)**：
   - 打通弹窗、快捷键、侧栏与外部接口的数据联动，条目新建、编辑、删除、收藏切换或模板导入时，同时驱动搜索弹窗与 Dock 侧栏平滑差量刷新，并保持当前滚动条位置不跳跃。
4. **高密度样式与多主题无障碍适配 (`tokens-r187.scss` & `index.scss`)**：
   - 将 `.xlc-dock` 纳入 `$roots` 根选择器，完全继承 R187 视觉基座与明暗主题；
   - 在 Windows `forced-colors: active` 高对比度无障碍模式下，为列表行、过滤胶囊与搜索框赋予专属 1px CanvasText 边框与透明背景保护。
5. **自动化测试与负向门禁验证**：
   - 新增 `tests/r377-dock-view-mvp.test.cjs` 专项测试套件；
   - 注入负向突变 137（破坏列表行原生 `draggable` 拖拽属性），门禁精准拦截红灯，恢复后复验全绿；
   - 单元测试增至 **1011/1011 项全绿**。
