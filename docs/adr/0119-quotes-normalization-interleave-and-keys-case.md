# ADR 0119：引号智能规范化、多行穿插交替合并与对象键名风格转换 (Quotes Normalization, Line Interleaving & Object Keys Case Conversion)

## 状态
已接受，T-0395~T-0399（2026-10-29）。

## 背景与上下文
在思源笔记内容资产层的高频使用与文本工程场景中，存在三类高频实用需求：
1. **跨来源复制文本的引号混用与排版清洗**：
   在从网页、PDF、聊天记录等来源录入或整理笔记时，引号常常处于直引号（`" '`）、中文弯引号（`“ ” ‘ ’`）与直角引号（`「 」 『 』`）杂糅状态。用户在公文排版、出版标准或技术写作中，常需要将选中文本一键规范化为统一格式；
2. **多行列表穿插交替合并（双语/问答对）**：
   在双语对照制作（如一段英文一段中文）、问答卡片（逐行问题与逐行答案）以及版本比对时，用户需要将两段多行文本按行两两穿插合并，并支持多余行的平滑续接或截断控制；
3. **API 联调与配置模型中的键名风格批量重构**：
   在数据模型、JSON 配置或多行 Properties 文本中，对象键名经常需要在驼峰（`camelCase`）、蛇形（`snake_case`）与短横线（`kebab-case`）之间批量重构，用户需要纯函数无损转换所有键名而不影响数据值。

## 决策与落地
1. **文本标点两端引号智能配对与规范化引擎 (`normalizeSmartQuotes`)**：
   - 纯函数实现，支持在 `straight` (直引号)、`curly` (中文弯引号) 与 `corner` (直角引号) 之间批量互转；
   - 动作菜单接线「“” 规范化引号为中文弯引号并复制」与「「」 规范化引号为直角引号并复制」，表单格式栏接入「✦ 规整引号」。
2. **多行文本交替穿插合并引擎 (`interleaveLines`)**：
   - 纯函数实现，支持等长与不等长多行交替合并，支持 `keepExceeding` 选项；
   - 动作菜单接线「🔀 前后两段列表多行交替穿插合并并复制」，表单格式栏接入「✦ 交替合并」。
3. **JSON / Properties 键名风格批量转换引擎 (`convertObjectKeysCase`)**：
   - 纯函数实现，深度递归解析 JSON 结构或多行 Properties 键值对，安全重构键名；
   - 动作菜单接线「🔤 转换属性键名为驼峰命名 (camelCase) 并复制」与「🔤 转换属性键名为蛇形命名 (snake_case) 并复制」，表单格式栏接入「✦ 键转驼峰」。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r345-quotes-interleave-and-keyscase.test.cjs` 专项测试；
   - 注入负向破坏直引号规范化输出与对象键名大小写转换，确认两项负向测试均被精准拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 901/901 项。
