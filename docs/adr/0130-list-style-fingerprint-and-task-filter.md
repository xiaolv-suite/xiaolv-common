# ADR 0130：Markdown列表样式双向批量互转、轻量指纹哈希宏与任务待办项状态筛选 (List Style Conversion, Fingerprint Macro & Task Filter)

## 状态
已接受，T-0450~T-0454（2026-10-29）。

## 背景与上下文
在思源笔记常用内容资产的日常流转、结构重整与任务清单管理场景中，存在三类高频实用痛点：
1. **Markdown 无序与有序列表双向批量互转**：
   用户在梳理步骤笔记、文档大纲或操作规范时，常常需要将无序圆点列表（`- `, `* `, `+ `）批量转换为连续编号的有序数字列表（`1. `, `2. `, `3. `），或反向转回无序列表。转换时必须深度支持多级嵌套子列表，不同缩进层级拥有独立的编号计数栈，并保护待办复选框（`[ ]`）不被破坏；
2. **轻量短字符指纹生成引擎与 `{{xlc:fingerprint}}` 动态宏**：
   在资源防伪、代码资产版本戳、缓存失效后缀以及条目快速唯一标识时，标准的 UUID（36位）或 MD5（32位）过于冗长且影响排版美观。用户需要一段极短（6~12位）、分布均匀、纯字母数字组合的高性能十六进制哈希指纹；
3. **Markdown 任务列表项状态过滤与批量提取**：
   在编写每日早晚报、Sprint 冲刺回顾或待办复盘时，笔记中常常混排着数十条未完成（`- [ ]`）与已完成（`- [x]`）的任务项。用户需要一键仅提取所有未完成项（以便复制到新一天的日记中继续跟踪），或仅提取所有已完成项（用于周报汇报），并支持剥离方括号复选框标记直接产出纯净文本列表。

## 决策与落地
1. **Markdown 无序列表与有序列表双向批量互转引擎 (`convertListStyle`)**：
   - 纯函数实现，通过缩进层级计数器字典（`Map<number, number>`）精确维护各嵌套层级编号；
   - 支持双向互转与起始编号自定义，保留任务列表项复选框与行内文本结构；
   - 动作菜单接线「🔢 转换为有序数字列表 (1. 2. 3.) 并复制」与「• 转换为无序圆点列表 (- ) 并复制」，表单格式栏接入「✦ 有序列表」与「✦ 无序列表」。
2. **字符串轻量级高散列指纹生成引擎 (`generateShortHash`) 与 `{{xlc:fingerprint}}` 动态宏**：
   - 纯函数实现，基于 64 位双轮正反向 FNV-1a 算法，输出短小（默认 8 位，支持 4~32 位截取）、分布均匀的十六进制指纹；
   - 扩展动态宏体系 `{{xlc:fingerprint|hello}}`、`{{xlc:fingerprint:6|hello}}`、`{{xlc:fingerprint|10|hello}}`；
   - 动作菜单接线「🏷 计算 8 位轻量指纹 (Fingerprint) 并复制」，表单格式栏接入「✦ 8位指纹」，表单变量栏补充 `{{xlc:fingerprint|hello}}`。
3. **Markdown 任务待办项状态筛选提取引擎 (`filterTaskItems`)**：
   - 纯函数实现，支持按 `pending`（未完成）或 `completed`（已完成）状态精准提取任务行；
   - 支持 `stripCheckbox: true` 选项自动剥离 `[ ]` 标记，生成整洁的项目清单；
   - 动作菜单接线「📋 仅提取未完成待办事项 (- [ ]) 并复制」与「✅ 仅提取已完成待办事项 (- [x]) 并复制」，表单格式栏接入「✦ 未完成待办」。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r356-liststyle-fingerprint-and-taskfilter.test.cjs` 专项测试；
   - 负向突变 91 破坏列表有序转换输出，突变 92 破坏任务状态过滤，两项负向测试均被精确拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 944/944 项。
