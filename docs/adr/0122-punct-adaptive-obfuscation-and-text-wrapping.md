# ADR 0122：中英混排自适应标点纠错、安全文本混淆与多行定宽折行 (Adaptive Punctuation, Text Obfuscation & Line Column Wrapping)

## 状态
已接受，T-0410~T-0414（2026-10-29）。

## 背景与上下文
在思源笔记内容资产层的高频使用与文本工程场景中，存在三类高频实用需求：
1. **中英混排上下文自适应标点纠错**：
   在混合语言笔记中，用户从不同平台复制文本时，中文字符间常夹杂半角逗号句号（如 `你好,世界.这是测试`），或者英文字符后跟随了中文全角标点（如 `Hello，world。`）。单纯的全角转换会破坏小数（如 `3.14`）和千分位金额（如 `1,000,000`）。需要具备上下文感知的自适应标点纠错引擎，在保护数值与代码的同时纠正语境标点；
2. **轻量文本安全混淆与临时掩码**：
   在技术演示、公开分享笔记或导出通用模板时，除直接星号掩码外，用户常需要将部分敏感字符串（Token、测试凭据、密钥样本）通过对称可逆算法（如 ROT13）或极客字符（Leet）进行混淆伪装，并在宏中支持调用；
3. **固定列宽格式化与智能折行（Word Wrap）**：
   在生成终端帮助文档、纯文本邮件、代码注释块或固定排版文本时，超长单行文本容易溢出视图。需要纯函数按固定列宽（如 80 字符）智能折行，西文在词界断开，中文按双字符宽度并在字间自然折行。

## 决策与落地
1. **中英混排数字与全半角标点智能自适应纠错引擎 (`normalizePunctuationAdaptive`)**：
   - 纯函数实现，前接汉字后接汉字/行尾的半角标点自动纠正为全角（`，。！？：；`）；
   - 英文单词间的全角标点自动转为半角加空格（`, `, `. ` 等）；
   - 严格保护数值小数与千分位金额不受破坏；
   - 动作菜单接线「🀄 中英混排自适应标点纠错并复制」，表单格式栏接入「✦ 自适应标点」。
2. **文本轻量安全混淆与加解密引擎 (`obfuscateText`) 与 `{{xlc:obfuscate}}` 动态宏**：
   - 纯函数实现，支持对称可逆 `rot13` 与 `leet` 极客替换；
   - 扩展动态宏体系 `{{xlc:obfuscate|rot13|HelloWorld}}`、`{{xlc:obfuscate:rot13|...}}` 与 `{{xlc:obfuscate|leet|...}}`；
   - 动作菜单接线「🔒 ROT13 对称可逆混淆/解密并复制」，表单格式栏接入「✦ ROT13混淆」，表单变量栏补充 `{{xlc:obfuscate|rot13|Hello}}`。
3. **多行文本固定列宽格式化与智能折行引擎 (`wrapTextLines`)**：
   - 纯函数实现，支持自定义最大列宽（默认 80）、行前置缩进（`indent`）及西文词界保护（`wordBreak`）；
   - 中文字符按双宽度计算并支持字间自然换行；
   - 动作菜单接线「📄 按 80 列宽度智能折行并复制」，表单格式栏接入「✦ 宽度折行」。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r348-punctadaptive-obfuscate-and-wrap.test.cjs` 专项测试；
   - 注入负向破坏自适应标点替换与 ROT13 字符位移，确认两项负向测试均被精准拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 913/913 项。
