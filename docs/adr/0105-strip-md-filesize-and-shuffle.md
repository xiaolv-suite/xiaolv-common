# ADR 0105：Markdown 格式剥离纯文本、字节容量格式化与多行随机洗牌宏 (Strip Markdown, Byte Size Formatting & Line Shuffling)

## 状态
已接受，T-0325~T-0329（2026-10-28）。

## 背景与上下文
在思源笔记内容资产层的高频使用与多渠道流转中，用户面临三项典型文本与数据呈现痛点：
1. **Markdown 语法外发污染**：
   在向邮件、即时通讯工具（微信、钉钉）或纯文本系统粘贴时，Markdown 粗体（`**`）、标题（`#`）、代码围栏（```` ``）或超链接（`[text](url)`）会产生排版干扰，需要快速净化为干净纯文本；
2. **字节数字难以直接感知**：
   在附件清单、音视频素材与下载说明中，原生数值（如 `1048576`、`2560000`）难以直观阅读，需要轻量格式化为 `1.00 MB`、`2.44 MB`；
3. **多行清单随机打乱抽样需求**：
   在团队点名、排班轮值、随机测试用例抽查时，用户需要对多行文本进行公平、无偏的随机洗牌（Shuffle）。

## 决策与落地
1. **Markdown 格式语法剥离纯文本引擎 (`stripMarkdownFormatting`)**：
   - 纯函数实现，剥离标题、粗体、斜体、删除线、行内/围栏代码、引用符号与水平分割线，提取超链接为纯正文；
   - 动作菜单接线「📄 剥离 Markdown 格式为纯文本并复制」，表单格式栏接入「✦ 纯文本」。
2. **字节容量友好格式化引擎 (`formatByteSize`) 与 `{{xlc:filesize}}` 动态宏**：
   - 纯函数实现，以 1024 为基数自适应换算为 `B`、`KB`、`MB`、`GB`、`TB`、`PB`，支持自定义小数位数与负数；
   - 扩展动态宏体系 `{{xlc:filesize|2097152}}` 与 `{{xlc:filesize|1536|1}}`；
   - 动作菜单接线「💾 字节转易读容量单位并复制」，表单变量栏补充 `{{xlc:filesize|1048576}}`。
3. **多行文本公平随机洗牌打乱引擎 (`shuffleLines`)**：
   - 纯函数实现，基于标准 Fisher-Yates 洗牌算法，保持集合元素完整，默认忽略空行；
   - 动作菜单接线「🔀 随机打乱行顺序 (Shuffle Lines) 并复制」，表单格式栏接入「✦ 随机打乱」。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r331-strip-md-filesize-and-shuffle.test.cjs` 专项测试；
   - 注入负向破坏容量格式化与纯文本断言，确认两项负向测试均被精准拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 846/846 项。
