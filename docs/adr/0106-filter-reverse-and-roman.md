# ADR 0106：多行文本关键词过滤、字符级安全反转与罗马数字转换宏 (Line Filtering, Character Reversal & Roman Numerals)

## 状态
已接受，T-0330~T-0334（2026-10-28）。

## 背景与上下文
在思源笔记常用内容资产层的高频复用与文本工程场景中，存在三类高频实用需求：
1. **多行文本特征筛选与噪声排除**：
   在分析日志、排查配置、提取特定格式条目时，用户需要快速保留包含关键词（或排除匹配特征）的行；
2. **字符级逆序翻转（Unicode/Emoji 安全）**：
   在校验算法、特殊编码、回文分析或排版镜像中，字符串逆序反转容易因 UTF-16 代理对切分引发乱码（如 Emoji 变空心问号）；
3. **罗马数字与阿拉伯数字互转**：
   在文献引用、学术章节目录、法律条款大纲等模板编写中，罗马数字（`I, II, IV, XIV, MMXXVI`）与阿拉伯数字互转属于刚性需求。

## 决策与落地
1. **多行文本关键词与正则行过滤引擎 (`filterLines`)**：
   - 纯函数实现，支持保留匹配行与反转排除匹配行（`invert: true`）；
   - 支持大小写敏感度与行首尾预清洗控制；
   - 动作菜单接线「🔍 过滤非空非注释行并复制」。
2. **Unicode 与 Emoji 安全字符逆序反转引擎 (`reverseText`) 与 `{{xlc:reverse}}` 动态宏**：
   - 纯函数基于 `Array.from` 安全迭代 Unicode 码点，完整保护双字节代理对与 Emoji；
   - 扩展动态宏体系 `{{xlc:reverse|TEXT}}`；
   - 动作菜单接线「🔄 字符逆序反转并复制」，表单格式栏接入「✦ 字符反转」，表单变量栏补充 `{{xlc:reverse|文本}}`。
3. **罗马数字与阿拉伯数字双向转换引擎 (`romanToArabic`/`arabicToRoman`)**：
   - 纯函数实现，支持 1~3999 区间整数与标准罗马数字双向精准互转，非法字符串安全校验；
   - 动作菜单接线「🏛 罗马数字转阿拉伯数字并复制」与「🏛 阿拉伯数字转罗马数字并复制」，表单格式栏接入「✦ 罗马数字」。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r332-filter-reverse-and-roman.test.cjs` 专项测试；
   - 注入负向破坏行匹配计数与字符反转断言，确认两项负向测试均被精准拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 850/850 项。
