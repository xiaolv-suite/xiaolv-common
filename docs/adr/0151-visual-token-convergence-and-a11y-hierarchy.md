# ADR 0151：视觉感知层现代化、设计令牌收敛与无障碍强化 (Visual Token Convergence & A11y Hierarchy)

## 状态
已接受，T-0564~T-0568（2026-10-29）。

## 背景与上下文
随着插件功能（多模态、树状大纲、差异合并、设置健康体检）不断迭代，生产样式表 `index.scss` 中积累了一定历史视觉残留：
1. **硬编码色值残留**：出现多达 59 处十六进制与旧思源蓝（`rgba(53, 117, 240, ...)`）散落定义，阻碍主题动态适配与对比度保证；
2. **拟物与渐变割裂**：出现拟物渐变按钮（`linear-gradient`）及脏感内阴影（`box-shadow: inset`）；
3. **阴影方向与距离散乱**：浮层与弹窗缺乏清晰的三档空间投影层次；
4. **控件状态与微交互不齐**：部分控件缺失 8 态（默认/悬停/按下/聚焦/选中/禁用/忙态/错误）标准映射，按键有突兀抖动位移；
5. **数字等宽与排版粗糙**：统计与序号数字在刷新时字符抖动，未统一定义 `tabular-nums`。

## 决策与落地
本轮严格执行 **A 档策略（只改样式不动结构）**，不动任何功能逻辑、数据结构与文案语义，以 `docs/design/prototype.html`（v4 原型）和 `docs/design/design-spec.md` 为唯一权威基线：

1. **统一系统三档阴影体系 (`tokens-r187.scss`)**：
   - 建立 `--xlc-shadow-sm`（第一档微浮起/卡片边缘）、`--xlc-shadow-md`（第二档下拉/Popover/浮卡）、`--xlc-shadow-lg`（第三档模态弹窗）；
   - 由浅色（`rgba(41, 34, 72, ...)`）与深色（`rgba(0, 0, 0, ...)`）调色板严格对称派生，暗色非死黑反色，正文对比度达 14.1:1。
2. **全量清除硬编码与拟物残留 (`index.scss`)**：
   - 彻底消灭全部 59 处十六进制硬编码颜色（0 hex 残留）；
   - 彻底清除 4 处拟物渐变按钮（0 linear-gradient 残留）；
   - 清理所有脏感凹陷内阴影，规范列表行左侧指示条；
   - 阴影全量收拢至三档统一标准。
3. **补齐控件 8 态与三级按钮层级**：
   - 为按钮与输入框规范定义默认、悬停、按下（`scale(0.98)` 微触感）、聚焦（`focus-visible` 2px 轮廓）、选中、禁用、忙态（`aria-busy="true"` wait 指针）与错误态；
   - 统一收拢为 Primary（主色反白）、Secondary/Outline（表面色带线）、Ghost（透明次级文字）三级按钮。
4. **排版质感与无障碍强化**：
   - 全局注入数字等宽排版：为序号、使用次数、行号、日期、快捷键等声明 `font-variant-numeric: tabular-nums`；
   - 完善 `@media (prefers-reduced-motion: reduce)` 全局规则，动效时长清零、关闭 transform 过渡，杜绝交互等待延迟；
   - 强化 Windows `forced-colors: active` 与 `prefers-contrast: more` 无障碍适配。
5. **自动化测试与负向门禁验证**：
   - 新增专项测试 `tests/r381-design-tokens-and-a11y.test.cjs`；
   - 注入负向突变 141（向 index.scss 注入违规十六进制颜色），门禁精准拦截红灯，恢复后复验全绿；
   - 单元测试增至 **1022/1022 项全绿**。
