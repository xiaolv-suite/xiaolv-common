# ADR 0120：数字度量单位规范间距、字符集清洗过滤与 NanoID 动态宏 (Unit Spacing Formatting, Character Set Filtering & NanoID Generation)

## 状态
已接受，T-0400~T-0404（2026-10-29）。

## 背景与上下文
在思源笔记内容资产层的高频使用与文本工程场景中，存在三类高频实用需求：
1. **中英文技术写作中的度量单位排版规范**：
   在技术文档、测试报告与量化写作中，国际排版规范要求数值与计量单位（如 `100 MB`, `3.5 GHz`, `50 kg`）之间保留一个半角空格，而日常快速输入或从不同系统复制时往往紧贴混排（如 `100MB`）。用户需要一键对文本进行单位间距规范化，同时保持百分比与温度符号紧贴数字不被破坏；
2. **字符集提取与特定字符流净化**：
   在清洗文本语料、提取核心中文内容或生成干净变量名时，用户常需要针对特定字符集进行过滤：例如仅保留汉字（过滤所有英文字母与标点符号）、仅保留字母数字、或者剔除表情符号与特殊标点；
3. **轻量紧凑的随机唯一标识符生成**：
   在技术模板、短链接命名或测试 ID 填充中，36 位的标准 UUID 往往过长，难以作为文件短名或紧凑 Key。用户需要 8~16 位紧凑、URL 安全且高随机度的唯一标识符（NanoID）。

## 决策与落地
1. **中英混排数字与度量单位规范间距引擎 (`formatUnitSpacing`)**：
   - 纯函数实现，覆盖数据存储速率（`MB`, `GB`, `Kbps` 等）与物理电气单位（`kg`, `km`, `GHz`, `ms`, `kW` 等 30+ 常见度量单位）；
   - 自动在数值与单位间插入规范单空格，保持现有空格与百分比符号不受影响；
   - 动作菜单接线「📏 规范数字与度量单位间距并复制」，表单格式栏接入「✦ 单位间距」。
2. **文本字符集提取与特定字符清洗过滤引擎 (`filterCharacterSet`)**：
   - 纯函数实现，支持 `chinese-only`, `alphanumeric-only`, `ascii-only`, `strip-punctuation`, `strip-emoji` 等 5 种过滤模式；
   - 动作菜单接线「🀄 仅提取纯汉字字符并复制」与「🔤 仅提取纯字母与数字并复制」，表单格式栏接入「✦ 纯字母数字」与「✦ 仅留汉字」。
3. **紧凑 URL 安全唯一随机标识生成引擎 (`generateNanoId`) 与 `{{xlc:nanoid}}` 动态宏**：
   - 纯函数实现，基于 62 个 URL 安全大小写字母与数字字符集生成随机序列；
   - 扩展动态宏体系 `{{xlc:nanoid}}`（默认 10 位）与自定义长度 `{{xlc:nanoid|16}}`、`{{xlc:nanoid:12}}`；
   - 动作菜单接线「🆔 生成紧凑唯一 NanoID (10位) 并复制」，表单格式栏接入「✦ 插入NanoID」，表单变量栏补充 `{{xlc:nanoid|12}}`。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r346-unitspacing-charset-and-nanoid.test.cjs` 专项测试；
   - 注入负向破坏单位规范间距插入与纯汉字提取，确认两项负向测试均被精准拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 905/905 项。
