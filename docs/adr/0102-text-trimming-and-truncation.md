# ADR 0102：多行文本高级空白修剪、对象属性引号规范化与定长截断宏 (Text Trimming, Object Quotes Normalization & Truncation)

## 状态
已接受，T-0310~T-0314（2026-10-28）。

## 背景与上下文
在思源笔记常用内容资产层的高频复用与对外分发场景中，用户面临三个典型的文本格式治理需求：
1. **行首尾与文档边缘多余空白污染**：
   从聊天窗口、PDF 或网页复制的段落常伴随首尾多行空行，或每行末尾携带不可见空格与制表符；代码片段粘贴后经常残留整块不必要的公共前置缩进；
2. **编程语言配置与 JSON 格式属性引号不一致**：
   在技术配置、JSON 片段与提示词参数编写中，用户经常在带双引号键名（`"key": "value"`）与不带引号键名（`key: "value"`）之间转换，或将 Python 字典单引号格式转换为标准 JSON 双引号；
3. **文本卡片展示与摘要预览定长截断需求**：
   在卡片标题、列表摘要、通知提醒、短信模板中，经常需要将长文本或某动态变量截断到指定字数，并优雅追加省略号 `...` 或 `…`。

## 决策与落地
1. **多行文本高级空白修剪引擎 (`trimLinesAdvanced`)**：
   - 纯函数实现，支持三维度清洗：去除整篇首尾连续空行（`trimDocumentEnds`）、清理每行末尾空格（`trimTrailing`），以及自适应剔除非空行最小公共缩进（`trimCommonIndent`）；
   - 动作菜单接线「🧹 行首尾空白修剪并复制」，表单格式栏接入「✦ 净首尾」。
2. **JSON/JS 对象键名与单双引号标准化引擎 (`normalizeObjectQuotes`)**：
   - 纯函数实现，支持 `to-json`（键名加双引号、单引号值转双引号）与 `to-js`（双引号标识符键转无引号）；
   - 动作菜单接线「🔣 属性名转双引号规范 (JSON) 并复制」，表单格式栏接入「✦ 转JSON键」。
3. **文本定长截断与动态省略宏体系 (`truncateText` / `{{xlc:truncate}}`)**：
   - 纯函数实现，支持指定最大长度与自定义省略号后缀（默认 `...`）；
   - 扩展动态宏体系 `{{xlc:truncate|30|TEXT}}` 与冒号子命令 `{{xlc:truncate:10|TEXT}}`；
   - 动作菜单接线「✂ 截断前 50 字并复制」，表单变量栏补充 `{{xlc:truncate|30|文本}}`。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r328-text-trim-and-truncate.test.cjs` 专项测试；
   - 注入负向破坏修剪结果与引号转换计数断言，确认两项负向测试均被精准拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 834/834 项。
