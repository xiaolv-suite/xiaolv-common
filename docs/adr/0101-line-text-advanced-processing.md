# ADR 0101：多行文本英文标题化、行倒序与行长排序及批量编号宏体系 (Multi-line Title Case, Reordering & Numbering Engine)

## 状态
已接受，T-0305~T-0309（2026-10-28）。

## 背景与上下文
在常用语管理与日常写作、开发、排版中，多行文本存在一系列结构规整需求：
1. **英文术语与标题大小写混乱**：
   从网页、论文、聊天窗口复制的英文清单往往全小写或随机大小写，用户需手工逐词调整大写规范；
2. **文本行顺序与长度反转需求频繁**：
   在编写 Prompt 提示词、正则匹配词表或排版调优时，长文本行常需按长度排序或逆序排列；
3. **多行列表缺乏快速结构化编号通道**：
   用户需要对分散的多行段落批量加上序号（1. / 01. / [1] / ① ），且支持在动态占位符宏模板中自动编号展开。

## 决策与落地
1. **多行英文标题化与首字母大小写规整 (`titleCaseLines`)**：
   - 纯函数实现，提供 `title`（标准英文标题）与 `sentence`（句首首字母大写）双模式；
   - 包含常见介词与冠词（`a`, `an`, `the`, `in`, `on`, `of`, `for`, `and`, `or`, `but`, `to` 等）小写保护；
   - 动作菜单接线「🔤 英文标题大小写规整 (Title Case) 并复制」，表单格式栏接入「✦ 英文标题」。
2. **多行文本倒序与按行长排序 (`reverseLines`/`sortLinesByLength`)**：
   - 纯函数实现，`reverseLines` 倒序反转行；`sortLinesByLength` 支持按字符长度升序（从短到长）与降序（从长到短）；
   - 动作菜单接线「↕ 多行倒序 (Reverse Lines) 并复制」与「📏 按行长度升序排列并复制」，表单格式栏接入「✦ 多行倒序」。
3. **多行批量编号引擎 (`numberLines`) 与 `{{xlc:number}}` 动态宏**：
   - 纯函数实现，支持 `decimal`（1. ）、`padded`（01. ）、`bracket`（[1] ）与 `circled`（① ）格式；
   - 默认忽略空行且不计数（`ignoreEmpty: true`），支持指定起始序号 `startFrom`；
   - 扩展动态宏体系 `{{xlc:number:lines|TEXT}}` 与 `{{xlc:number|padded|TEXT}}`；
   - 动作菜单接线「🔢 批量编号多行文本 (1. 2. ) 并复制」，表单格式栏接入「✦ 批量编号」，表单变量栏补充 `{{xlc:number:lines|文本}}`。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r327-text-lines-advanced.test.cjs` 专项测试；
   - 注入负向破坏标题大写与行号计数断言，确认两项负向测试均被精准拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 830/830 项。
