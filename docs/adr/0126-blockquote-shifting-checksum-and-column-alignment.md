# ADR 0126：引用块层级升降、轻量校验和计算与多列等宽对齐 (Blockquote Level Shifting, Checksum Calculation & Column Alignment)

## 状态
已接受，T-0430~T-0434（2026-10-29）。

## 背景与上下文
在思源笔记内容资产层的高频使用与文本工程场景中，存在三类高频实用需求：
1. **多行引用段落层级整体升降调整**：
   在整理对话记录、邮件往来、文献批注或二级引用时，用户常需要将选中文本整体提升一层引用（如行首统一增加 `> `），或从多层嵌套中脱出一层引用（如将 `>> ` 降为 `> `），且需在无引用行处幂等安全回退；
2. **轻量短小的数据校验和与指纹计算**：
   在技术记录、接口配置比对、模板版本标识或数据完整性检测中，完整的 32 位 MD5/SHA256 散列往往过长，难以放入短文件名或标签中。用户需要 8 位的 CRC32 或 Adler32 轻量级校验和，并支持在宏体系中直接展开（`{{xlc:checksum|...}}`）；
3. **分隔符多列数据的垂直视觉对齐**：
   从 CSV、日志文件或简单键值清单中复制的内容往往因各字段长短不一而难以快速比对。用户需要一键将各列根据最大字符宽度（汉字占 2 宽，ASCII 占 1 宽）补空格对齐，形成整齐直观的视觉表格而无需包装为复杂 Markdown 表格。

## 决策与落地
1. **Markdown 引用块嵌套层级提升与降低引擎 (`shiftMarkdownBlockquotes`)**：
   - 纯函数实现，支持配置 `delta` 步长（`delta: 1` 升层，`delta: -1` 降层）；
   - 正则识别并剥离前导 `> `，空行与无引用行平滑处理；
   - 动作菜单接线「💬 引用层级批量升一级 (> -> >>) 并复制」与「💬 引用层级批量降一级 (>> -> >) 并复制」，表单格式栏接入「✦ 引用升层」与「✦ 引用降层」。
2. **字符串轻量校验和计算引擎 (`calculateChecksum`) 与 `{{xlc:checksum}}` 动态宏**：
   - 纯函数实现，直接复用内部预生成的 `CRC32_TABLE` 与 UTF-8 字节编码器，支持 CRC32 与 Adler32 算法；
   - 扩展动态宏体系 `{{xlc:checksum|123456789}}` 与子命令 `{{xlc:checksum:adler32|...}}`；
   - 动作菜单接线「🔏 计算 CRC32 校验和并复制」，表单格式栏接入「✦ 校验和」，表单变量栏补充 `{{xlc:checksum|hello}}`。
3. **文本行按分隔符等宽对齐填充引擎 (`alignDelimitedColumns`)**：
   - 纯函数实现，多行解析单元格并测量 CJK 双字节宽度，在各列右侧补空格实现垂直对齐；
   - 动作菜单接线「📐 按分隔符等宽对齐多列并复制」，表单格式栏接入「✦ 列对齐」。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r352-quoteshift-checksum-and-aligncol.test.cjs` 专项测试；
   - 注入负向破坏引用升降级与校验和计算，确认两项负向测试均被精准拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 929/929 项。
