# ADR 0104：多行文本单行合并与拆分、中文大写金额规范化与首字母缩写提取宏 (Join Lines, Chinese Currency & Initials Extraction)

## 状态
已接受，T-0320~T-0324（2026-10-28）。

## 背景与上下文
在思源笔记内容资产层的实际复用场景中，存在三类典型文本处理与商务财务需求：
1. **多行与单行参数形态互转频繁**：
   在把多行文本转换为单行参数（如逗号分隔 `a, b, c`、分号分隔 `a; b; c`）时，手工逐行退格换行极其繁琐。反之，将逗号/分号/竖线分隔的字符串拆分为多行文本也很常见；
2. **商务合同与财务报销中的中文大写金额计算**：
   在商务报价、财务发票、采购申请等常用语模板中，阿拉伯数字金额转中文大写汉字（如 `1234.56` -> `壹仟贰佰叁拾肆元伍角陆分`）属于刚性需求；
3. **英文术语与标题首字母缩写提取**：
   在整理术语表、编写代码常量或项目命名时，用户经常需要从长词组（如 `Central Processing Unit`）中一键提取大写缩写 `CPU`。

## 决策与落地
1. **多行合并单行与单行拆分多行引擎 (`joinLinesWithDelimiter`/`splitTextToLines`)**：
   - 纯函数实现，`joinLinesWithDelimiter` 支持自定义分隔符（默认 `, `），支持忽略空行与每行首尾多余空白预清洗；
   - `splitTextToLines` 自动支持中英文逗号、分号、竖线与制表符智能切词；
   - 动作菜单接线「🔗 多行合并为逗号行并复制」与「↵ 逗号/分号拆为多行并复制」，表单格式栏接入「✦ 连成单行」与「✦ 拆为多行」。
2. **中文人民币大写金额规范化引擎 (`formatChineseCurrency`) 与 `{{xlc:currency}}` 动态宏**：
   - 纯函数实现，涵盖负数、零角零分、整以及万/亿进位分节，彻底消除前导零与多重连续零；
   - 扩展动态宏体系 `{{xlc:currency|1234.56}}`；
   - 动作菜单接线「￥ 金额转中文大写汉字并复制」，表单变量栏补充 `{{xlc:currency|1234.56}}`。
3. **文本词组首字母与缩写提取引擎 (`extractInitials`)**：
   - 纯函数实现，提取词组英文单词或中文汉字首字，支持自定义分隔符与大写模式；
   - 动作菜单接线「🔤 提取首字母缩写 (Initials) 并复制」，表单格式栏接入「✦ 提首字母」。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r330-text-join-currency-and-initials.test.cjs` 专项测试；
   - 注入负向破坏多行合并结果与金额大写断言，确认两项负向测试均被精准拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 842/842 项。
