# ADR 0129：标识符命名法智能互转、数字区间序列生成宏与Markdown表格转CSV数据导出 (Identifier Naming Style, Sequence Macro & Table to CSV)

## 状态
已接受，T-0445~T-0449（2026-10-29）。

## 背景与上下文
在思源笔记常用内容库的实际使用与文本编辑流转场景中，存在三类高频实用痛点：
1. **多行变量与标识符命名法智能互转**：
   在技术文档、数据表设计或代码重构笔记中，用户常常需要将多行变量标识符在驼峰式（`camelCase`）、帕斯卡式（`PascalCase`）、蛇形下划线（`snake_case`）、常量全大写（`UPPER_SNAKE_CASE`）以及短横线（`kebab-case`）之间进行批量转换。同时必须保护前导与尾随下划线（如 Python 私有成员 `_secret` 或魔术方法 `__init__`）不受破坏，并保留代码行前缩进；
2. **数字区间序列生成引擎与 `{{xlc:seq}}` 动态宏**：
   在编写测试用例、报表序号或待办清单时，用户需要快速生成一段连续数字区间（如 `1, 2, 3, 4, 5` 或 `001, 002, 003`），甚至需要指定步长或按行分隔（`1\n2\n3`），无需手动敲入；
3. **Markdown 表格转 CSV / TSV 格式数据导出**：
   用户在思源笔记中整理的 Markdown 表格，经常需要复制到 Excel、电子表格或数据库客户端中。需要纯函数自动剥离 Markdown 分隔线（`| --- | --- |`），解析单元格，并遵循 RFC 4180 标准对含逗号、引号的单元格进行安全引号转义包裹。

## 决策与落地
1. **变量与标识符命名法智能互转引擎 (`convertIdentifierNamingStyle`)**：
   - 纯函数实现，支持 `camel`、`pascal`、`snake`、`constant`、`kebab` 5 种命名法转换；
   - 智能识别驼峰与下划线分词边界，保护前导/尾随符号（`_`, `$`, `-`）与行首缩进；
   - 动作菜单接线「🐫 变量命名法转驼峰 (camelCase) 并复制」与「🐍 变量命名法转下划线 (snake_case) 并复制」，表单格式栏接入「✦ 驼峰转换」。
2. **数字区间序列快速生成引擎 (`generateNumericSequence`) 与 `{{xlc:seq}}` 动态宏**：
   - 纯函数实现，支持正序递增、逆序倒数、自定义步长（`step`）、前导零补齐（`padWidth`）与自定义分隔符（`delimiter`），内建 2000 项防无限循环硬上限；
   - 扩展动态宏体系 `{{xlc:seq|1|10}}`、`{{xlc:seq|1|10|2}}`、`{{xlc:seq:line|1|5}}`、`{{xlc:seq:pad|1|5|3}}`；
   - 动作菜单接线「🔢 根据数字区间生成序列清单并复制」，表单格式栏接入「✦ 序号序列」，表单变量栏补充 `{{xlc:seq|1|10}}`。
3. **Markdown 表格转 CSV / TSV 格式数据导出引擎 (`markdownTableToDelimited`)**：
   - 纯函数实现，跳过 Markdown 对齐分隔线行，自动还原转义管道符 `\|`；
   - 严格遵循 RFC 4180 CSV 规范，对包含逗号或双引号的内容执行 `""` 转义并加双引号包裹；
   - 动作菜单接线「📊 转换 Markdown 表格为 CSV 格式并复制」，表单格式栏接入「✦ 表格转CSV」。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r355-namingstyle-seqmacro-and-tablecsv.test.cjs` 专项测试；
   - 负向突变 89 破坏命名法转换输出，突变 90 破坏表格分隔线过滤，两项负向测试均被精确拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 940/940 项。
