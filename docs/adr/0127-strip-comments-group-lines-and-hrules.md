# ADR 0127：代码注释安全剥离、行模式分组聚合与分割线标准化防误伤 (Code Comments Stripping, Lines Grouping & HRules Normalization)

## 状态
已接受，T-0435~T-0439（2026-10-29）。

## 背景与上下文
在思源笔记内容资产层的高频使用与文本工程场景中，存在三类高频实用需求：
1. **代码注释安全剥离且保护字符串字面量**：
   在技术文档中复用代码或准备向外分享纯净脚本时，用户需要一键移除所有行级与块级注释（`//`, `/*...*/`, `#`, `--`）。由于粗暴的正则替换容易将字符串内部的 `//`（如 `http://`）或 `#`（如 `#ffffff`）误伤删除，必须依赖精准的状态机进行字面量保护；
2. **多行日志或分类清单按模式自动分组聚合**：
   在分析系统日志、处理报错报告或梳理待办任务时，多行记录往往按行首标记前缀混排（如 `[ERROR]`, `[INFO]`, 或 `类别:`）。用户需要纯函数一键按前缀分组归类，输出结构化的大纲标题与条目统计；
3. **Markdown 水平分割线规范化与防 Setext 二级标题误伤**：
   从其他格式转换而来的 Markdown 经常包含不同样式的分割线（`***`, `___`, `* * *`, `---`）。Markdown 语法中，如果上一行文字后直接紧贴 `---`，CommonMark 解析器会无条件将其解析为 Setext H2 标题！这是极易导致文档排版崩坏的高频暗坑。必须在规整分割线的同时，自动保证分割线前后有空行隔离。

## 决策与落地
1. **代码文本注释批量安全剥离引擎 (`stripCodeComments`)**：
   - 纯函数实现，通过词法状态机精确跟踪 `'`、`"`、反引号包裹与转义字符 `\`；
   - 仅在非字符串语境下剥离单行注释与块级注释；
   - 动作菜单接线「🧹 剥离代码单行与块级注释并复制」，表单格式栏接入「✦ 剥离注释」。
2. **文本行按前缀模式分组聚合引擎 (`groupLinesByPattern`)**：
   - 纯函数实现，提取行首方括号标记或冒号前缀，自动分类聚合并在各组二级标题下输出计数；
   - 动作菜单接线「📑 按前缀模式分组聚合多行并复制」，表单格式栏接入「✦ 分组聚合」。
3. **Markdown 水平分割线标准化与防标题误伤引擎 (`normalizeHorizontalRules`)**：
   - 纯函数实现，识别任意语法的有效水平分割线，统一收敛为目标样式（默认 `---`）；
   - 上下方有非空行文字时自动追加空行，彻底根除 Setext 标题误解析风险；
   - 动作菜单接线「📏 规范化分割线 (防误伤标题) 并复制」，表单格式栏接入「✦ 规整分割线」。
4. **自动化门禁与双向严格负向验证**：
   - 新增 `tests/r353-stripcomments-grouplines-and-hrules.test.cjs` 专项测试；
   - 注入负向破坏注释剥离逻辑与分割线空行隔离，确认两项负向测试均被精准拦截；
   - 源码恢复后复验全绿通过，单元测试总数达到 932/932 项。
