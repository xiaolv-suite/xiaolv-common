# ADR 0150：Dock 侧栏多维分类树状折叠大纲、高级拖拽多模态与端到端体验加固 (Dock Tree Folding & Drag Modalities)

## 状态
已接受，T-0554~T-0563（2026-10-29）。

## 背景与上下文
在完成阶段 1 原生侧边栏 (Dock) MVP 落地后，随着用户内容资产规模增加（数十至数百条常用语），单列扁平列表存在两类典型痛点：
1. **分类组织缺乏层级感**：多分类混排导致长列表浏览翻查费力，用户迫切需要分类树状折叠大纲；
2. **拖拽落块形态单一**：此前仅支持纯文本/Markdown 拖拽，但在思源双链笔记体系下，用户非常希望直接按住修饰键拖出思源双链块引用或动态同步嵌入块；
3. **端到端体验断点**：多选模式下按 Esc 误退窗口丢勾选、全库穿透模式缺乏快捷路径清除等。

## 决策与落地
1. **多维分类树状折叠大纲 (`DockView`)**：
   - 全库浏览态自动按 `category` 聚合为树状折叠组头（包含展开指示符 `▾`/`▸` 与计数徽标）；
   - 支持各分类独立折叠/展开，并于内存集合中自适应保持折叠状态；
   - 搜索过滤或切换至常用/最近/收藏范围时，无缝切换为全展开扁平检索模式，兼顾大纲与检索速度。
2. **高级拖拽多模态数据注入 (Drag Modalities)**：
   - 增强 `dragstart` 调度器：
     - 普通拖拽：写入标准 Markdown 正文；
     - `Alt` 键修饰拖拽：自动包装并生成思源双链块引用链接（`((id 'title'))`）；
     - `Shift` 键修饰拖拽：自动包装并生成思源同步嵌入块语法（`{{select ...}}`）。
3. **侧栏专属轻量右键菜单 (Dock Context Menu)**：
   - 条目行右键弹出专用快捷操作浮层（插入、复制纯文本、复制块引用、打开源块、切换收藏、编辑条目），点击外部或 Esc 安全销毁。
4. **端到端体验与状态留存加固**：
   - **P0 草稿防丢失**：新建表单误按 Esc 或遮罩关闭时，自动暂存内存会话草稿，重开表单时提供“恢复草稿”横幅，彻底杜绝手打内容意外丢失；
   - **P1-1 多选 Esc 保护**：多选模式下按 Esc 优先退出多选模式，防止搜索弹窗误关导致勾选状态全部丢失；
   - **P1-2 换库即时联动**：设置面板切换内容库文档时，通过统一总线即时驱动 Dock 侧栏无感差量刷新；
   - **P1-3 路径快捷清除**：搜索框支持 `Alt+Backspace` 一键清除 `in:` 路径限定符；
   - **P2-1 极限窄屏防挤压**：为侧栏微标增加 `min-width: 28px` 与 `flex-shrink: 0`；
   - **P2-2 别名实时查重**：新建表单别名输入框增加 150ms 防抖查重，冲突时行内实时呈现黄色预警微标。
5. **自动化测试与负向门禁验证**：
   - 新增 `tests/r380-dock-tree-and-drag-modes.test.cjs` 专项测试；
   - 注入负向突变 140（破坏 Alt 拖拽块引用多模态），门禁精准拦截红灯，恢复后复验全绿；
   - 单元测试增至 **1016/1016 项全绿**。
