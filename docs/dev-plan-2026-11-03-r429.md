# 近期新功能全方位审查与缺陷修复账本（2026-11-03 · T-0821~T-0826 / R429）

## 一、 背景与审查目标

依据用户指令：「再次通过 pnpm e2e:isolated，逐项测试，梳理每行代码，确认没有 bug。」

对近期引入的 Epoch 7 全套生态基础设施（`lvNoticeKit`、`withDocLock`、`lvSurfaceStack`、`lvActivity`、`lvAi`、`lvBackup`、`lvLaunchpad`、`lvOmnisearch`）及全链路交互开展了深度走查与门禁审查。在运行 `pnpm e2e:isolated` 及全套质量门禁时，精确捕获并定位了以下核心缺陷与体验瑕疵并完成修复：

1. **`src/service/library.ts` 索引构建代数竞态（T-0821）**：`ensureIndex` 复用 `buildingPromise` 时未核验代数，导致在写入/纳管并调用 `invalidateIndex()` 后，并发进来的构建可能复用写操作前的旧扫描结果，在真实思源宿主 E2E 步骤 19 中偶发引发原地纳管条目无法在索引中查找到的陈旧构建污染问题；
2. **`src/libs/lv-notice-kit.ts` 文档写锁 `withDocLock` 内存泄漏（T-0822）**：`map.set(docId, prev.then(...))` 存入的是链接 Promise，而 `finally` 块比较的是原始 `current`，比较恒为 `false`，导致文档 ID 永远无法从全局锁 Map 中释放；
3. **`lvSurfaceStack` 键盘仲裁截断与多级浮层 Esc 断链（T-0823）**：通知中心初始化时常驻入栈无活跃卡片、单层退出时无 `keep` 语义误把自己弹出、以及发现弹窗/确认窗/Dock 侧栏菜单漏接焦点栈，导致交互审计 B24 关闭确认窗与真实宿主 E2E 步骤 12 Dock 右键菜单按 Esc 无法关闭；
4. **`src/service/ai.ts` 模板智能展开缺少降级保护（T-0824）**：`aiSmartExpandTemplate` 裸调 `lvAi.chat`，在无网络或模型不可用时抛出未捕获异常；
5. **小驴罗盘条目数徽标动态化与穿透搜索多字段匹配（T-0825）**：罗盘注册项中徽标原写死为 `"常用 18 项"`，重构为响应内容库条目增删差量更新真实条目数；穿透搜索补齐条目别名（alias）与简码（shortcode）多维度匹配；
6. **异步操作时序与思源内核重试弹性加固（T-0826）**：移除 `pushToSourceBlock` 中过早阻断重试的 `maxRetries: 0`；在真实宿主 E2E 测试中引入轮询等待机制消除高频网络 I/O 带来的临界抖动。
