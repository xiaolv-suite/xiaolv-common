## [0.9.7] — 2026-10-27

连续粘贴取用队列 (Paste Queue)、JSON 智能格式化压缩与选区包裹快捷命令：多字段极速出栈、⌥⇧Q 连续粘贴、⌥⇧W 选区包裹、JSON 格式化/压缩与 762 项单测全绿通过。

### 新增与核心优化

- **连续粘贴取用队列 (Paste Queue / Stacking Mode)**：
  - 在常用列表多选勾选条目后，底部操作栏新增「📋 设为取用队列」；
  - 注册全局快捷键 `⌥⇧Q`（或 `Alt+Shift+Q`）与协议命令 `xiaolv.common.pasteQueueNext`，在任意目标位置按下快捷键依次出栈自动填入下一项，无需反复呼出弹窗，专为工单填写、财务报销、多字段录入打造。
- **选区快速包裹快捷指令 (Surround Selection)**：
  - 注册全局快捷键 `⌥⇧W`（或 `Alt+Shift+W`）与编辑器右键菜单项「用常用模板包裹选区」；
  - 自动检测活动编辑器选区并无缝衔接 `{{xlc:selection}}` 模板，秒级实现代码围栏、高亮卡片与批判思考卡包裹。
- **JSON 智能格式化与压缩引擎 (`formatJsonText` / `compactJsonText`)**：
  - 在动作菜单中针对复合 JSON 数据提供「{} 格式化 JSON 并复制 (2空格缩进)」与「{} 压缩 JSON 并复制 (单行紧凑)」；
  - 纯函数安全转换，非 JSON 内容优雅保持原样。

### 验证与已知边界
