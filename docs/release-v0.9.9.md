## [0.9.9] — 2026-10-27

动态常用语变量推导向导与中英文标点智能规整：静态文本一键转活模板、标点双向智能清洗、全全角标点规整与 771 项单测全绿通过。

### 新增与核心优化

- **常用语文本一键参数化与动态变量推导向导 (`autoParameterizeText`)**：
  - 在新建/编辑条目表单中新增「✦ 变量推导」按钮；
  - 智能深度侦测静态话术中的 11 位手机号、邮箱地址、具体日期、金额货币与客户尊称（如“尊敬的王经理您好”），一键替换为活模板占位符 `{{xlc:ask:...}}` 与 `{{xlc:date}}`，大幅降低零门槛制作专业动态模板的成本。
- **中英文标点智能归一化与修正引擎 (`normalizePunctuation`)**：
  - 支持 `to-cjk` 模式：将中文语境下误打的半角英文逗号、句号、问号、叹号、冒号、分号与括号转换为规范的中文全角标点，智能跳过数字小数（如 3.14）与 URL 链接；
  - 支持 `to-ascii` 模式：将中文标点转换为 ASCII 半角标点；
  - 表单快捷变量条新增「✦ 标点规整」一键工具。

### 验证与已知边界

- 全套质量门禁：单元测试 771/771 项全绿通过、TypeScript 类型检查 0 错误、错误处理静态扫描、密钥安全扫描、安装包根相对结构校验（15 项必需资源健全）全部通过。
