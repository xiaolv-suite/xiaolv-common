## [0.9.8] — 2026-10-27

URL 跟踪分析参数深度清洗、列表序号一键规整与剪贴板类型智能识别：URL 纯净化、列表多风格转换 (Markdown/带圈数字)、剪贴板类型自适应与 767 项单测全绿通过。

### 新增与核心优化

- **URL 分析追踪参数安全深度清洗 (`stripUrlTrackingParams`)**：
  - 针对从 Bilibili、微信、小红书、淘宝、知乎、Twitter、Spotify 等分享链接携带的冗长跟踪参数（`spm_id_from`、`vd_source`、`utm_*`、`share_token`、`si`、`fbclid`、`igshid` 等）进行精准清除；
  - 完整保留业务查询参数（如 `id`、`page` 等）与 Hash 锚点；
  - 表单变量快捷栏新增「✦ 净URL」一键清洗工具，动作菜单提供「🔗 清洗 URL 追踪参数并复制」。
- **列表格式一键排版净化与多范式重构 (`normalizeListFormatting`)**：
  - 识别混合混乱的列表编号（`1、`、`1. `、`（1）`、`①`、`一、`、`-`、`*` 等），一键转换为标准 Markdown 有序列表（`1. `、`2. `）或无序列表；
  - 支持一键转换为中文社交与邮件常用的微信带圈序号（`①`、`②`、`③`）；
  - 表单变量快捷栏新增「✦ 规整列表」按钮，动作菜单提供快捷转换并复制。
- **剪贴板暂存类型智能嗅探与自适应**：
  - 剪贴板视图中的条目不再硬编码为纯文本，而是实时基于内容推断类型（代码围栏、URL、Markdown、表格），呈现专属类型徽标。

### 验证与已知边界

- 全套质量门禁：单元测试 767/767 项全绿通过、TypeScript 类型检查 0 错误、错误处理静态扫描、密钥安全扫描、安装包根相对结构校验（15 项必需资源健全）全部通过。
