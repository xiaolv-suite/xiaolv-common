## [0.9.6] — 2026-10-27

盘古之白中英文智能排版、制表符表格转 Markdown 与语境问候宏：中英文自动规范空格、Excel 制表符表格一键转 Markdown、自然时间时段问候宏 `{{xlc:greeting}}`、剪贴板多选合并收录与 759 项单测全绿。

### 新增与核心优化

- **盘古之白中英文智能排版规范化 (`formatPanguSpacing`)**：
  - 在汉字 (CJK) 与英文字母、数字之间自动插入标准规范空格，清理全角标点符号两端的多余空格；
  - 智能保护 Markdown 链接、URL、代码块/行内代码与动态宏 `{{xlc:...}}` 不受破坏；
  - 表单快捷变量条新增「✦ 盘古排版」按钮，条目动作菜单新增「✦ 盘古排版 (中英文加空格并复制)」快捷动作。
- **制表符表格一键转标准 Markdown 表格 (`tsvToMarkdownTable`)**：
  - 针对从 Excel、WPS 或网页复制的制表符 (`\t`) 分隔表格，智能嗅探并一键转换为标准 Markdown 表格（自动补齐列宽与对齐分隔线 `| --- |`）；
  - 表单快捷变量条新增「⊞ 转MD表格」按钮，剪贴板条目动作菜单提供「⊞ 转为 Markdown 表格并复制」。
- **语境自适应时间段问候宏 (`{{xlc:greeting}}`)**：
  - 占位符引擎新增 `{{xlc:greeting}}`，根据当前时间段自适应展开为“早上好”、“中午好”、“下午好”、“晚上好”或“夜深了”；
  - 支持 `{{xlc:greeting|en}}` 输出英文问候（Good morning / Good afternoon / Good evening）、`{{xlc:greeting|formal}}` 商务正式问候与 `{{xlc:greeting|simple}}`。
- **剪贴板/全域多选「⊞ 合并收录」闭环**：
  - 多选勾选 2 项及以上剪贴板或全域条目时，底部操作栏新增「⊞ 合并收录 (N项)」，一键拼接多条碎片沉淀为一份结构化思源块资产。
