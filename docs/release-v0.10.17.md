# 小驴常用 v0.10.17 发布说明

## 概述

小驴常用 `v0.10.17` 带来 CSV/TSV 转结构化 JSON 引擎、文本字数与行数度量宏及 Markdown 待办清单批量重置工具。
当前版本仅在本地仓库更新，全套 822/822 项单元测试全绿通过，遵照用户指令封禁期不推送远程 GitHub。

## 详细变更

1. **CSV/TSV 转结构化 JSON 纯函数 (`csvToJson`)**：
   - 智能嗅探 `\t`, `,`, `;` 分隔符，遵循 RFC 4180 标准（支持带逗号的双引号字段与 `""` 转义）；
   - 动作菜单新增「{} 转换为 JSON 数组并复制」；
   - 表单快捷格式栏新增「✦ 表格转JSON」。

2. **文本统计与度量动态宏体系 (`{{xlc:count}}`)**：
   - 支持动态宏：`{{xlc:count:chars|...}}`、`{{xlc:count:lines|...}}`、`{{xlc:count:words|...}}` 与 `{{xlc:count:cjk|...}}`；
   - 表单快捷变量栏新增 `{{xlc:count:chars|文本}}` 快捷按钮。

3. **Markdown 待办清单批量状态切换 (`toggleMarkdownTaskStatus`)**：
   - 智能识别 `- [ ]`、`* [ ]`、`+ [ ]` 及其完成态，支持全选完成、全选重置与状态反转；
   - 动作菜单接线「☐ 全部重置待办状态 (- [ ]) 并复制」与「☑ 全部完成待办状态 (- [x]) 并复制」；
   - 表单快捷格式栏接入「✦ 重置待办」。

- 静态检查：`pnpm run check` 0 错误；
- 错误抛出检查：`pnpm run check:errors` 全绿；
- CHANGELOG 对齐：`pnpm run check:changelog` 全绿；
